# 라이브 데모 체크리스트 — 6분

발표 전: 맑은 고딕 설치와 PPTX 줄바꿈을 확인합니다. 네트워크·wasm 초기화·3D 로드를 확인하고 브라우저 확대는 100%에서 시작해 프로젝터에 맞춥니다. Pages, 로컬 서버, Issue #29 탭을 미리 열고 오프라인 영상을 준비합니다. S1~S5 버튼은 계산 중 비활성화되므로 완료 후 다음을 누릅니다.

레시피 기본값은 8단, 영상과 결과 표는 12단. 데모 전에 단 수 확인 (`sim/params.json` recipe.layers.value, S1·S4 결과).

문제 발생 시: 새로고침 한 번 후 프리셋 재선택 → 준비된 로컬 탭 → 로컬 영상 순으로 전환합니다. 3D만 실패하면 결과 표와 그래프로 계속합니다. 시간 지연 시 선택 시연(S5·두 히터)을 생략합니다.

로컬 실행은 **저장소 루트**에서 `web/serve_local.sh` → <http://localhost:8000/web/> 입니다. `_site` 조립을 포함하므로 단순 `web/` 폴더 서버로 대체하지 않습니다. 로컬 준비와 영상 재생 확인은 발표 전에 마칩니다.

영상: `~/Desktop/MSE489/기말보고서/영상/MSE489_HBM적층본더_시연.mp4` (저장소 밖). [Release demo-video](https://github.com/ycpark06/hbm-stacking-edu-sim/releases/tag/demo-video)는 네트워크가 있을 때의 다운로드 수단입니다. 남은 시간에 맞는 영상 장면을 재생하고 8장으로 복귀합니다.
