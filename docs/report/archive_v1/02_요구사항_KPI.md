# 2. 요구사항과 정량 KPI

**중간 대비 바뀐 점**

- 원문 KPI·요구의 해석을 유지하고 수치 구분 규칙을 명시했다.
- 적층 시편과 층간 간격, 휨 2단계·결함 면적률 판정을 추가했다.
- 자기 접합 온도 미달과 선택적 헤드 보정 목표를 구분했다.
- 순차 전원·냉각 FAIL/REVIEW와 가정값, 관찰·참고값을 반영했다.

## 2.1 대상 공정과 시편

| 항목 | 기말 조건 | 구분·근거 |
|---|---|---|
| 공정 | TC-NCF / MR-MUF | 설계 범위, `docs/PLAN.md` 1절 |
| 다이 | 5×5 mm, 기본 100 μm·비교 50 μm | 설계 목표, `docs/requirements.md` 3절 |
| 층 수 | 2 / 4 / 8 / 12단 | 설계 목표, 같은 파일 3절 |
| 범프 | Cu pillar + 솔더 캡 | 설계 목표, 같은 파일 3절 |
| 층간 간격 | 기본 15 μm, 선택 7~30 μm, 20 μm는 시험 칩 선택지 | 문헌값, 같은 파일 3절·`sim/params.json:geometry.interlayer_gap` |
| 공급·관찰 | NCF 부착 다이 트레이 / 필름 없는 다이, 유리·석영 하부 관찰 | 설계 구성, `docs/PLAN.md` 8절 |

층간 간격의 기본값은 Lee et al., ECTC 2023의 MR-MUF 적층 자료를 따르고, 얇은 간격의 TC-NCF 공개 사례와 조사 자료를 함께 기록한다(`docs/research/params_research.md` 1절). 7~30 μm는 요구사항의 선택 범위이며 모든 간격에서 충전·접합이 보장된다는 뜻이 아니다. 중간의 트레이 공급과 박형 다이 크랙 회피 개념은 유지하되, 50 μm는 휨 민감도를 보는 비교 조건으로 추가했다.

**구분 규칙.** 원문 수치는 원문 KPI·요구, 근거를 두고 정한 판정 기준은 설계 목표, 확정 설정은 설계값, 공개 재료·공정 자료는 문헌값, 온도차에서 모델로 구한 접촉 저항은 역산 추정값이다. 미공개 조건은 가정값으로 표시한다. 업체 주장은 판정 없는 관찰 항목이고 질량·높이는 참고값이다. 문헌 수치를 판정 기준으로 채택한 경우도 그 기준 자체는 설계 목표로 쓴다(`docs/requirements.md` 1절).

## 2.2 원문 KPI와 해석

**해석 원칙.** KPI는 PBL 강의자료에 적힌 정보만으로 해석한다. 원문에 없는 수치(승온 속도, 각도, 하중 제어 오차, 질량 등)는 KPI에 넣지 않는다. 그런 수치는 2.4절의 설계 목표로 따로 두고 근거를 밝힌다. 원문에 근거가 없는 값은 판정 대상이 아닌 참고값으로만 기록한다(2.5절).

| KPI | 원문 표기 (7쪽) | 원문의 관련 정보 | 해석 | 검증 방법 |
|---|---|---|---|---|
| 정합 | ±1 μm 광학 정합 반복 정밀도 | 9쪽: 피듀셜 검출 → Δx·Δy·Δθ → 아핀 보정으로 "정합 오차를 서브마이크론으로 수렴". 4쪽: X·Y·θ 정렬 | X·Y 방향 정합 반복정밀도 ±1 μm | 유리 테스트 다이를 30회 이상 배치하고 본딩 후 피듀셜 오프셋을 측정해 3σ로 판정 (광학 정렬값보다 엄격한 본딩 후 기준) |
| 가열 | 400 ℃ 펄스 히터 최고 온도 | 8쪽: "400 ℃ 가열 블록과 정밀 가이드 레일 사이에 MACOR 및 쿨링 자켓". 9쪽: 열전대 10 ms 피드백. 4쪽: 핫플레이트 상온~350 ℃ 이상 | 본딩 헤드의 펄스 히터가 최고 400 ℃에 도달 | 히터 열전달 해석 (7장) |
| 하중 | 50 N 본딩 하중 제어 정밀도 | 4쪽: 내장 로드셀로 가압력 정밀 측정·표시. 5쪽: "칩 두께 및 크기별 적정 가압력 설정 (크랙 방지 및 두께 균일도)". 9쪽: 로드셀 10 ms 피드백 | 최대 본딩 하중 50 N. 원문에는 제어 오차 수치가 없다 | 구동부 토크 계산 (6장) |
| 크기 | 600 mm 데스크톱 최대 풋프린트 | 3쪽: "실습형 데스크톱 반도체 장비". 6쪽: "대학 실습실 테이블에 설치 가능한 컴팩트 형태" | 풋프린트(바닥 면적)의 가로·세로 각각 600 mm 이하 | 3D CAD 외곽 치수 (11장) |
| 제어 주기 (원문 요구) | (9쪽 요구) | 9쪽: "로드셀 하중 데이터와 열전대 온도 신호를 10 ms 단위로 피드백" | 하중·온도 피드백 주기 10 ms 이하 | 제어 시뮬레이션 (10장) |

**정의상 주의.** 원문은 "광학 정합" 반복정밀도라고 썼다. 본 설계는 이것을 광학 정렬 직후가 아니라 본딩을 마친 뒤의 실제 배치 오차로 검증한다. 본딩 후 오차에는 광학 정렬 오차와 그 뒤의 Z 하강, 열팽창, 접촉 미끄러짐이 모두 들어가므로(5장), 본딩 후에 ±1 μm를 만족하면 광학 정합 KPI는 자동으로 만족한다. 에폭시 다이 부착은 경화 중 다이가 움직이므로, KPI는 접합재 없는 건식 배치로 검증하고 경화 중 이동량은 실습 측정 항목으로 둔다. 기말에서는 이 장비 반복정밀도와 별도로 아래층 대비 층간 정합을 설계 목표로 판정한다(2.6절).

## 2.3 해석 근거

**하중 50 N.** 원문은 50 N을 "제어 정밀도"로 표기했다. 50 N을 오차로 읽으면, 5쪽이 요구하는 "칩 두께 및 크기별 적정 가압력 설정"이 불가능해진다. 수 N 이하의 작은 하중을 50 N 오차로는 구분할 수 없기 때문이다. 따라서 50 N을 장비가 낼 수 있는 최대 가압력으로 해석한다. 하중 제어 오차는 원문에 수치가 없으므로 KPI로 두지 않고, 2.4절의 설계 목표로 정한다.

**600 mm 풋프린트.** 풋프린트는 장비가 차지하는 바닥 면적을 뜻한다. 원문은 한 변의 길이만 적었으므로 가로와 세로 모두 600 mm 이하로 해석한다. 높이는 풋프린트에 포함되지 않으므로 KPI 판정 대상이 아니다.

**400 ℃.** 원문 8쪽이 400 ℃ 가열 블록을 정밀 가이드와 함께 언급하므로, 400 ℃는 본딩 헤드 쪽 히터의 최고 온도로 해석한다. 4쪽의 핫플레이트 "350 ℃ 이상"은 장비 예시 사진의 설명이며 KPI가 아니다. 기판 척 온도는 3장에서 따로 정한다.

## 2.4 설계 목표 (원문 KPI 아님)

아래 값은 원문 KPI가 아니라, 설계와 해석의 기준으로 쓰기 위해 설계자가 정한 목표다. 판정표에서도 원문 KPI와 구분해 표시한다.

| 설계 목표 | 값 | 근거 |
|---|---|---|
| 하중 범위·제어 오차 | 저 레인지 0.2–5 N ±(0.05 N + 1 %), 고 레인지 2–50 N ±(0.1 N + 1 %), 과하중 정지 55 N | 실제 R&D 본더의 2레인지 구성 (3장 3.1절) |
| 히터 승온·안정도·냉각 | 승온 ≥ 20 K/s, 안정도 ±2 ℃, 400→100 ℃ 냉각 ≤ 60 s | 실제 R&D 본더 승온 6–20 K/s (Finetech lambda) |
| 기존 적층 척 / 신규 리플로우 척 | 기존 200 ℃ / 리플로우 250 ℃·1~3 K/s 공정 목표 | 기존 척은 중간 설계 목표, 리플로우는 별도 모듈의 문헌 프로파일 기반 공정 목표 (`calc/hardware/README.md`) |
| 각도 정합 | ±0.005° (3σ) | 10×10 mm 다이 모서리 변위를 0.6 μm 이하로 유지 (5장 5.4절) |
| 하중 루프 주기 | 1 ms | 접촉 충격 억제 (3장 3.5절). 원문 10 ms보다 엄격 |

다이 크기에 따른 압력도 함께 관리한다(p = F/A). 같은 50 N이라도 10×10 mm 다이에서는 0.5 MPa, 2×2 mm 다이에서는 12.5 MPa다. 그래서 실습 매뉴얼에 다이 크기별 하중 상한을 둔다(13장).

| 파생 요구 | 값 | 근거 |

| 가이드·스테이지 온도 상승 | ≤ 0.5 K | 강재(11.5 ppm/K) 100 mm 구간은 1 K 상승에 1.15 μm 팽창 |

## 2.6 적층 공정 판정과 관찰 항목

| 항목 | 기준 | 구분·근거 |
|---|---|---|
| 층간 정렬 | 아래층 대비 축별 3σ ≤ 1 μm | 설계 목표, 원문 ±1 μm를 층 단위로 적용 |
| 휨 주의 | 절대 휨 > 간격/4, 15 μm일 때 3.75 μm | 설계 목표, 범프 미접촉을 조기에 경고하기 위해 1/4 채택 |
| 휨 불량 | 절대 휨 > 20 μm (±20 μm 밖) | 설계 목표, Lee et al., ECTC 2023의 220 ℃ MR 접합 안정 범위라는 문헌값을 교육용 판정으로 채택 |
| 결함 면적률 | ≤ 1 % 양호, >1~5 % 주의, >5 % 불량 | 설계 목표, 업체 기준 비공개. 보이드+미충전 합산을 지향하는 교육용 기준 |
| 접합 온도 미달 | TC-NCF 자기 접합 구간 최고 < 221 ℃ | 문헌 액상선 `solder.liquidus_snag`를 이용한 알람 규칙 |
| 헤드 온도 보정 | 자기 접합 최고를 액상선+10 ℃, 즉 231 ℃로 맞춤 | +10 ℃는 설계값, `judgement.bond_temp_margin_C` |

*표 근거: `docs/requirements.md` 4·6절, `sim/params.json:judgement`·`solder` (출처 문헌·구분 포함). 휨 판정은 전체 공정의 최대 절대 휨을 사용한다. 경계값은 표의 부등호대로 적용한다.*

접합 온도가 액상선과 같으면 미달이 아니다. 후속 층의 재가열은 자기 접합 온도 판정을 대체하지 않는다. MR-MUF는 리플로우 구간 최고로 같은 온도 충족 여부만 기록하고 해당 미달 알람을 내지 않는다. 온도 충족은 젖음·금속간화합물·접합 강도를 포함한 품질 보증이 아니다. 헤드 보정은 선택 옵션이며 기본은 꺼짐이다. 필요 헤드가 400 ℃ 원문 KPI를 초과하면 레시피를 거부한다(`docs/requirements.md` Issue #29 절).

NCF에는 정량 보이드 면적률 모델이 없어 결함률을 산출·판정하지 않는다. MR-MUF의 계산 면적률은 미충전만 포함하며 갇힌 보이드의 예측이 아니다. 따라서 계산된 미충전이 양호여도 합산 결함률의 실물 합격을 뜻하지 않는다(`docs/tcncf_mode_report.md`, `docs/stage4_model_update.md`). 누적 정렬, 사이클 시간, 열 이력·재가열은 관찰 항목이다. 업체 공개 주장은 회사·출처와 함께 표시만 한다.

## 2.7 운전 조건과 안전 한계

| 항목 | 조건 | 구분·출처 |
|---|---|---|
| TC-NCF 하중 | 기본 40 N, 선택 25~50 N | 설계값, `docs/requirements.md` 6절 |
| TC-NCF 승온 | 20 K/s, 문헌 80 ℃/s는 비교만 | 장비 설정 / 문헌 비교값, 같은 파일 6절 |
| 하중 제어 | 1 ms PI, FIRMWARE 속도 ±0.5 mm/s, 저레인지 기본 램프 1 N/s | 설계값, `firmware/README.md` |
| 경고 / 차단 | 52 N·410 ℃ / 55 N·420 ℃ | 안전 설계값, `firmware/README.md` |
| 히터 전원 | 헤드 400 W / 리플로우 척 150 W 순차, **두 히터 동시 통전 금지** | 설계값·SW 인터락, `calc/hardware/README.md`, `firmware/README.md` W7 |
| 정렬 | 정렬 온도 고정 + 도달 후 90 s 안정화 | 설계 절차, `calc/hardware/thermal_expansion.json` |
| 척 냉각 | 피크→180 ℃에서 4 K/s 이상 유지 | 설계 목표, `calc/hardware/reflow_heater.json` |

52 N 경고와 55 N 차단은 운전 허용 하중을 올리는 기준이 아니다. 원문 최대 하중은 50 N이다. 냉각은 최소 3.39 K/s·평균 4.1 K/s라는 계산 결과로 전 구간 유지 목표 **FAIL/REVIEW**다. 180 ℃ 아래는 관찰 항목이며, 풍량 100 L/min·h=400 W/m²K는 실측 전 가정값이다(7장 7.11절). 금형압력 3 MPa(문헌값)와 갭 입구 유효압력 기본 1 MPa(가정값)를 구분한다(`docs/requirements.md` 6절).

*중간 계승 수치 근거: 2.2~2.4절의 원문 해석·기존 목표·파생 요구는 `docs/report/midterm/02_요구사항_KPI.md`, 계산 근거는 `calc/midterm/error_budget.json`·`thermal.json`·`drive_calc.json`이다. 여기의 레인지·제어 오차·각도·승온·평행도 수치는 설계 목표이고 원문 KPI를 추가한 것이 아니다.*
