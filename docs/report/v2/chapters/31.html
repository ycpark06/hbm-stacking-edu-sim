9.2 모델에서 빠진 현상이
품질 판단을 제한한다

모델포함한 것미포함·주의
열다이 중심 절점·접촉 열저항범프 접합층 독립 온도·출력 제한 폐루프 결합
유동평행판·일정 점도·압력+모세관범프 투과도·필러 여과·공기 포획
NCF접촉·겔화·저점도 체류 경향정량 보이드. null을 0 %로 해석 금지
휨적층판 선형 탄성기판 구속·점탄성·경화 수축
정렬작은 변위의 복원력·마찰 잔여실제 미끄러짐·고온 평면도
CAD저장 자세의 형상 간섭전 스트로크·배관·케이블·볼트 접근

완성 스택과 척 기준점의 강체 동반 이동은 층간 상대 오차와 다르다. 실제 미끄러짐·열 휨을 측정하기 전까지 기준점 이동 계산으로 정합을 보증하지 않는다.

업체의 성능 주장은 관찰 항목이다. 이 모델이 재현하지 못한 현상을 입력을 임의 조절해 맞추지 않는다.
