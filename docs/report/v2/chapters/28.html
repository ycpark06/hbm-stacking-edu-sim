8.7 실행 환경의 차이를
모델 변경과 분리했다

문제 →단계 5 CAD에서 파일 읽기가, 단계 4 CI에서 수치 정확 일치가 실패했다.

원인 →Fusion의 ASCII 기본 인코딩과 V8 초월함수의 끝자리 차이였다.

왜 이렇게 →파일 해석은 UTF-8로 고정한다. 숫자 오차만 허용하고 판정·문자열·배열 길이는 정확 비교해야 한다.

결과인코딩 검사와 상대·절대 허용 비교를 적용했다.

검사전후
CAD #33 / PR #34인코딩 미지정입출력 UTF-8·ASCII 환경 검사
CI #37 / PR #38부동소수점 정확 일치상대 1e-12 + 절대 1e-15
판정 계약숫자 오차와 혼동 위험불량·문자열·배열 길이 정확 비교

이 허용치는 계산 재현성 검사의 수치 기준이다. 공정 합격 기준이나 정합 허용오차를 넓힌 것이 아니다. 실패가 나면 환경·입력·모델 변경 중 어느 원인인지 먼저 구분한다.
