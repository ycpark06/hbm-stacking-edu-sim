8.4 적분 포화 대응과
능력 초과 거부를 함께 넣었다

문제 →단계 2에서 고착 뒤 하중 초과가 크고 저레인지가 램프를 못 따라갔다.

원인 →출력·적분 제한이 없었고, 유효 강성×최대 속도가 요구 상승률보다 작았다.

왜 이렇게 →제어기 적분만 고쳐도 장비 능력은 늘지 않는다. 같은 유효 레시피로 포화 응답을 비교하고 능력 초과 입력은 거부한다.

결과anti-windup과 램프 검사를 적용했다. 원본 golden은 보존했다.

근거는 #6·#13·#15, PR #14·#16이다. 출력 제한 시 적분 누적을 막고 최대 속도와 유효 강성으로 레시피를 검증한다. 판정 구간 조정 뒤에도 원본 오차와 도달 시각은 관찰값으로 남겼다.

저레인지와 고레인지는 강성이 다르다. 서로 다른 모드·서로 다른 레시피의 초과량을 한 개선율로 제시하지 않는다.
