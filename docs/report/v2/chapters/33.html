10.1 다음 판단에 필요한
실패 조건을 남겼다

층별 온도·유동·정렬·제어를 같은 입력 기록에서 읽는다

공정 동작을 보여 주는 장비 모델에서, 입력 조건이 어떤 결과를 만드는지 설명하는 비교 도구로 범위를 넓혔다. 수치가 목표를 벗어난 이유를 열 경계·압력 구동·출력 제한·모델 전제와 연결했다.

지금 가능한 판단다음 근거가 필요한 판단
기본 레시피의 미달과 보정 필요 설정실제 접합층 온도·강도·보이드
가압 유동과 필러 규칙의 영향실제 압력 손실·누설·기포 포획
공통 제어기의 소프트웨어 재현센서·구동·독립 안전 회로
개념 조립체의 형상과 설계 도면고온 조립성·평행도·실물 반복정밀도

후속 작업은 새로운 성능 주장을 더하는 것보다 측정으로 가정의 범위를 줄이는 데 둔다. 열프로파일·기밀·안전 시험을 먼저 수행한 뒤 정합 예산과 품질 모델을 갱신하는 순서가 적절하다.
