05　장비 고도화 · 계산·모의 검증10
05　장비 고도화교육용 HBM 적층 본더

척 도면은 지지와 관찰을 구체화한다

적층 척과 리플로우 척은 교환 장착을 설명한다. 하드웨어 운전 전제는 적층 척=리플로우 척이며, 정렬 온도를 고정하고 안정화 절차를 적용한다. 두 척 사이 실제 이송은 검증하지 않았다.

상온 도면의 평면도와 평행도는 고온 변형의 보증이 아니다. 전면 지지·진공 유로·관찰 창과 범프 하중 분포를 제작 후 확인해야 한다.
