# 부록 C. 계산 상세·검증 조건

## 열과 보정

Cᵢ dTᵢ/dt = ΣGᵢⱼ(Tⱼ−Tᵢ). 접촉 열전도도는 면적 열저항의 역수 관계다. 다이 중심 절점의 자기 접합 구간 최고를 액상선과 비교한다. 보정은 이전 층 설정을 고정하고 필요한 헤드 설정을 이분법으로 찾는다.

접촉 저항이 커지면 같은 온도차의 열류는 줄어든다. 척으로 손실이 늘었다고 단정하지 않는다. 이상 헤드 경계는 실제 출력 제한 제어와 미결합이다.

근거: `sim/thermal.js · sim/test/bond_temp_results.json`

## 수지 유동

평행판의 압력 구동에 모세관 압력을 더한다. 유동 길이의 제곱은 시간·간격 제곱·유효압력에 비례하고 점도에 반비례한다. 미충전률은 충전 길이에서 계산한다.

일정 점도·평행판 가정. 범프 투과도·필러 여과·갇힌 공기·경화 점도 상승 미포함. 필러 규칙과 미충전은 별도 판정이다.

근거: `sim/muf.js · sim/test/stage4_results.json S5`

## 필름 스퀴즈

초기 필름 두께에서 하중·시간에 따른 BLT와 접촉을 계산한다. 초기 두께는 간격+여유다.

접촉·겔화·저점도 체류의 정성 경향이며 정량 보이드 모델은 없다. null을 영으로 해석하지 않는다.

근거: `sim/ncf.js · docs/tcncf_mode_report.md`

## 적층판과 정렬

각 층의 탄성·두께·열팽창에서 적층판의 합력·모멘트 평형을 구한다. 정렬은 복원력·감쇠·정지 마찰 잔여를 포함한다.

상온 선형 탄성, 기판 구속·점탄성·경화 수축 미포함. 작은 변위·젖음·접촉을 가정하며 TC 자기정렬은 이 모델에서 미적용이다.

근거: `sim/warpage.js · sim/alignment.js`

## 시간 경계와 통계

본더 점유는 층별 동작을 합산하고 배치 후공정은 별도로 합산한다. 정합 예산은 독립 오차의 RSS이며 단일 누적 표본은 반복 통계가 아니다.

배치 크기·병렬 설비·대기 시간 미설정으로 라인 UPH 미산출. 다른 입력·모드의 결과를 같은 개선율로 묶지 않는다.

근거: `sim/cycle.js · calc/midterm/error_budget.json`

## 제어·기구 상세의 재현

공통 C 제어와 HAL을 구분하고 host/wasm의 고정 입력 출력을 비교한다. 기구 손계산은 CAD 치수 원본과 연결한다.

원본 golden을 보존한다. 구조·열·지그 계산의 상세 수식·단위·조건은 아래 링크의 원본을 따른다. 실물 HAL·독립 차단은 미검증이다.

근거: `firmware/README.md · calc/hardware/README.md · calc/midterm/`

## 계산식과 단위

- 열 전도: G=A/R_area [W/K]. 다이 반두께 전도 저항과 계면 접촉 저항을 직렬 합성하며 헤드와 척 경계를 각각 적용한다.
- 평행판 충전: ΔP_cap=2γcosθ/h, x²=h²(ΔP_in+ΔP_cap)t/(6η). x는 충전 길이, h는 간격, η는 점도다. x=L일 때 완료 시간이며 구현 경계는 sim/muf.js를 따른다.
- 스퀴즈 기준식: 1/h²−1/h₀²=4Ft/(3πηR⁴). 등가 원판·일정 점도 가정이다. NCF의 구현·공정 점도 조건은 sim/ncf.js와 기존 판 4·15장을 따른다.
- 적층판: [A B; B D]{ε₀,κ}={Nᵀ,Mᵀ}. 층별 E·ν·α와 두께 좌표로 적층 강성 및 열 합력·모멘트를 적분한다. 자유판의 작은 변형 가정이다.
- 정합 예산: σ_total=√Σσᵢ². 보정 후 독립 잔차를 합성한다. 누적 단일 표본 x·y와 3σ를 혼합하지 않는다.
- 램프 능력: dF/dt≤k_eff·v_max. 유효 강성과 속도 제한을 넘는 레시피는 거부한다.
- 본더 점유: t_bonder=Σ층 Σ동작 t. 배치 후공정은 리플로우+디스펜스+충전+금형 내 경화+후경화를 따로 합산한다.

식의 상수는 수학적 계수이며 새 공정 입력이 아니다. 상세 전개·단위·경계 조건과 검증 벡터는 연결된 원본을 따른다.
