# v2 검증 인계

브랜치 docs/report-v2에서 작성했다. 커밋·push·PR·index 변경과 Chromium 실행은 하지 않았다. 실제 로컬 표지 개인정보 파일은 열지 않았다. PDF·페이지 PNG는 Claude의 허용된 환경에서 생성·검토해야 한다.

## 산출물과 쪽 구성

전체 파일 목록·빌드 명령은 [README](README.md), 순서·쪽 제목·근거는 [pages.json](pages.json)에 있다. 본문 35쪽·표지 1쪽, 요약본 9쪽·표지 1쪽이다. 별도 부록 인쇄 원고는 57쪽이며 파라미터 전표 207개를 길이에 따라 묶었다. 부록 A에는 범위 내 문제 기록 15건을 작업 단계로 재구성했다. 부록 B는 모든 kind/source/note를 유지한 전표, C는 식·계산 경계·상세 원본 연결, D는 기존 판 이력이다.

본문 배치: 요약 1, 목차 2, 요구 3–4, 중간 요약 5–7, 공정 비교 8–9, 하드웨어 10–13, 디지털 트윈 14–16, S1·S2·S3·S5·S4 17–21, 개선 사례 22–29, 한계 30–32, 결론 33, 참고문헌 34–35. 승인 계획과 같다.

## 경로 갱신과 보존 예외

갱신: web/cad.html(도면 이미지·기존 절 근거 링크), web/tools/assemble_site.sh(도면 PNG 복사), 루트 README.md의 보고서 한 줄, docs/report/README.md, docs/presentation/README.md. 추가 탐색에서 찾은 docs/presentation/deck.json의 출처 경로도 갱신했다. 루트 README의 영상 및 다른 줄은 변경하지 않았다. PPTX 바이너리는 수정하지 않았다.

현재 `git grep`의 tracked 텍스트 검색은 바이너리 PPTX를 제외하면 0건이다. 이동된 archive_v1은 아직 untracked이므로 이 결과만으로 보존 디렉터리까지 0건이라고 판단하면 안 된다. 전체 실제 파일을 rg로 별도 검색한 결과는 아래와 같다. git index는 수정하지 않았다.

**원본 파일 그대로 보존과 저장소 전체 문자열 0건은 충돌한다.** 이동된 원본의 README.md 6건, fig/ch17_figs.py 2건, fig/ch17_edit_log.json 90건은 이력과 실행 안내의 옛 경로를 그대로 갖는다. 원본 해시 보존을 우선했으며 이를 숨겨 0건으로 보고하지 않는다. 기존 빌드는 archive_v1에서 실행하면 ROOT·fig 상대 참조가 성립한다. 기존 README의 루트 실행 명령은 옛 경로이므로 새 README의 빌드 안내를 따른다.

## 커밋 단위 제안

- docs: 기존 보고서 판 보존 및 웹·발표 출처 경로 갱신
- docs: v2 본문·요약본·부록 원고와 논리 검토 반영
- build: v2 그림·PDF 빌드·숫자 및 정적 검사

실제 커밋·push·PR은 Claude 담당이다. 최종 PDF 생성·페이지 검증 후 그 결과와 공개 PDF만 해당 단위에 추가한다.
