# 주제 선정 배경 검증 인계

브랜치 `docs/report-background`, worktree `wt-rep3`에서 원고와 정적 검사를 갱신했다. 커밋·push는 수행하지 않았다. Chromium 실행·PDF 빌드·페이지 확인은 Claude 담당이다. 개인정보 표지 파일은 읽지 않았다. 저장 PDF는 재생성하지 않았으므로 현재 원고와 쪽수가 다르다.

## 추가 내용과 쪽 구성

- `chapters/background.html`: **1.2 주제 선정 배경**, 본문 **2쪽**. 1.1 요약 바로 뒤에 한 쪽을 넣었다. 수업에서 두 공정을 배운 계기, 같은 층수·칩 조건의 비교 목적, 안전한 반복 실습을 위한 시뮬레이터 선택 이유를 담았다.
- SVG 상자·연결선으로 가열 횟수 → S1(7.1절, 21쪽), 빈틈 채우기 → S5(7.4절, 24쪽), 위치 맞추기 → S2(7.2절, 22쪽)를 연결했다. S3 휨(7.3절, 23쪽)·S4 시간(7.5절, 25쪽)은 점선으로 보조 연결했다.
- 강의 근거는 저장소 기존 판 1장 문제 정의·4장 4.9절 공정 물리와 `docs/requirements.md`만 사용했다. 새 물리 수치·업계 자료·시장 자료는 추가하지 않았다. 결과는 기존 원고와 저장 JSON을 따른다.
- `summary/02.html`: 본문 2쪽의 기존 요구·계승 설계 아래에 선정 배경을 반 쪽 분량으로 합쳤다. 본보고서 1.2절과 결과 절·쪽 번호를 연결했다.
- `pages.json`, 목차, 요약본 연결 범위, 생성 HTML 두 파일과 검사 전표를 갱신했다. 기존 장·절 번호는 유지하며 본문 쪽은 기존 2쪽부터 한 쪽씩 뒤로 이동한다.

## 검사 결과와 재검사

```sh
python3 docs/report/v2/build_v2.py --html-only
python3 docs/report/v2/check_toc.py --text-dir /tmp/report-background-text
python3 docs/report/v2/check_numbers.py
python3 docs/report/v2/check_static.py
python3 -m py_compile docs/report/v2/build_v2.py docs/report/v2/check_toc.py docs/report/v2/check_numbers.py docs/report/v2/check_static.py docs/report/v2/make_figs.py
git diff --check
```

- 목차: 11장·38절, 본문 제목·머리말·꼬리말·요약 연결 통과. 표시 텍스트의 버전 문구 0건.
- 수치: JSON 표시 93회·고유 키 53개, S1 별도 저장값 24개, 그림 출처 SHA256 모두 통과. 새 물리 수치는 추가하지 않았다.
- 정적: 링크·이미지 경로 통과, 기존 판 79개 파일 해시 보존. 이전 인계에서 누락으로 기록했던 `cad_light_all.png`는 현재 작업 트리에 존재한다. 이미지 내용의 적합성은 PDF·PNG에서 확인한다.
- 수동 숫자 문맥은 `number_check.json`과 `수치대조표.md`를 따른다. 이 목록과 그림 내부 치수·축 눈금은 자동 수치 검증 통과에 합산하지 않는다.
- Python 구문 컴파일과 공백 검사는 위 명령으로 확인한다. 시뮬레이션 입력·모델·기존 그림은 변경하지 않았다.

## Claude PDF·페이지 확인

1. `python3 docs/report/v2/build_v2.py --pages-png /tmp/report-background-pages --check-overflow`로 공개 PDF·PNG·`render_check.json`을 생성한다. 예상 PDF는 본보고서 40쪽, 요약본 10쪽이다.
2. 본문 2쪽의 문단·SVG·근거·footer 간격, 상자 안 질문과 결과 문구, 점선 보조 연결을 확인한다. 흰 바탕·지정 색·Pretendard와 대체 글꼴 순서, 연결선과 글자의 겹침도 확인한다.
3. 본문 3쪽 목차에서 1.2절과 갱신한 모든 쪽 번호를 확인한다. 요약본 본문 2쪽의 기존 표와 추가 배경 사이 간격·반 쪽 분량·footer 넘침을 확인한다. 넘치면 문구나 배치를 조정하고 검사와 HTML 생성을 다시 실행한다.
4. 결과 21–25쪽의 S1·S2·S3·S5·S4 순서와 다이어그램의 절·쪽 번호를 대조한다. MR 가접 노출과 본접합 가열, NCF 정량 보이드의 부재, TC 자기정렬 미적용 전제가 유지되는지 확인한다.
5. 앞선 CAD 보강 쪽은 15–17쪽이며, 전체 색 CAD 이미지는 16·20쪽이다. 전체 색·분해 표시, 도면·배선도 판독성 및 기존 26쪽 온도 미달 사례의 조판을 확인한다. 저장 자세 간섭 결과를 전 스트로크·고온 조립성 검증으로 확대하지 않는다.
6. 이미지 로드·넘침·전체 PDF 쪽수·글꼴·쪽 번호를 확인하고 PDF 표시 텍스트를 추출해 버전 문구가 없는지 대조한다. 개인정보 표지는 별도 허용된 로컬 절차로 처리한다.

## 커밋 단위 제안

하나의 변경으로 묶는다: `docs(report): 주제 선정 배경과 비교 질문 연결도 추가`.

원고·SVG 스타일·쪽 순서·목차·요약 연결·장수 검사·생성 HTML·검사 전표·README·검증 인계를 함께 포함한다. 검증된 PDF·PNG 반영과 실제 커밋·push는 이번 작업에서 수행하지 않았다.
