#29　미달을 드러내고 보정을 선택한다

본보고서 8장 22쪽. 단계 4 / PR #28 작업 중, 12단 조건.

문제 →1·2층이 자기 접합 구간에서 액상선 221 ℃에 미달했다.

원인 →접촉 열저항을 반영하자 차가운 척 쪽 하부층 온도 미달이 드러났다.

왜 이렇게 →결과를 맞추려고 열저항 값을 바꾸지 않았다. 바꾸면 원인이 가려진다. 기본값은 두고 알람·헤드 보정을 선택한다.

결과보정 전 층 약 231 ℃, 필요 헤드 최대 약 341 ℃. 원문 KPI 400 ℃ 이내다.

열저항은 툴·척 각각 2×10⁻⁴ m²K/W의 역산 추정값이다. 기본 레시피는 별도로 보존한다. 보정 시 열저항·승온 속도·유지 시간은 유지하고 층별 헤드 설정을 바꾼다. 필요 온도가 한계를 넘으면 거부하며, 온도 통과만으로 접합 품질을 보증하지 않는다.
