# 요약

**설계 대상.** 학생이 다이 본딩 공정을 직접 관찰하고, 온도·하중·시간·도포량을 바꾸며, 결과를 수치로 검증할 수 있는 교육용 데스크톱 다이본더. 기본 공정은 에폭시 다이 부착이고, Cu pillar 열압착(TCB)을 확장 공정으로 둔다.

**구조.** 본딩 헤드(Z·θ, 400 ℃ AlN 펄스 히터, 판스프링 2레인지 하중, 로드셀, 잠금형 짐벌)는 대칭 프레임에 고정하고, 기판이 조동(200×100 mm) + 압전 미동(±0.5 mm, 10 nm) 2단 스테이지로 움직인다. 빔스플리터 듀얼 비전(1.73 μm/px)이 칩과 기판의 피듀셜을 한 프레임에 담는다. 유리 기판 + 하부 카메라, 측면 카메라, 레이저 변위센서로 보이드·필렛·BLT·휨을 관찰한다.

**원문 KPI 판정 (PBL 7, 9쪽, 모의 검증)**

| KPI | 목표 | 결과 | 판정 |
|---|---|---|---|
| 광학 정합 반복정밀도 | ±1 μm | 본딩 후 3σ 0.69 μm (대표) / 0.90 μm (보수) | 통과 |
| 펄스 히터 최고 온도 | 400 ℃ | 400 ℃, 승온 22 K/s, 냉각 45 s | 통과 |
| 본딩 하중 | 50 N | 최대 50 N, 0.2–5 N / 2–50 N 2레인지 | 통과 |
| 풋프린트 | 600 mm | 590 × 480 mm | 통과 |
| 피드백 주기 | 10 ms | 하중 1 ms, 온도 10 ms | 통과 |

**핵심 설계 결정과 근거**

| 결정 | 근거 |
|---|---|
| 조동 + 미동 2단 스테이지 | 단일 스테이지는 정합 3σ 1.49 μm로 KPI 실패 (5장) |
| 작은 히터(20×20×5 mm) + 설정 온도 도달 후 90 s 대기 | 승온 20 K/s 달성, 정렬 중 열드리프트 ≤ 0.26 μm (7장) |
| 대칭 기둥·대칭 Z 레일 프레임 | 50 N 측면 변위 74.6 → 0.054 μm, 1차 모드 40 → 177 Hz (8장) |
| NCC + 평탄화 보정 + 아핀 캘리브레이션 | 최악 조건 검출 0.031 px, 보정 없으면 1 mm에서 5.6 μm 오차 (9장) |
| 하중 루프 1 ms | 저하중 접촉 초과량을 10 ms 대비 6~26배 줄임 (10장) |
| 끼워맞춤 용도별 구분 (g6·h6·m6) | 미끄럼 끼워맞춤의 틈새가 정합 오차가 됨 (11장) |

**교육 활용.** 실습 5개(정렬 원리, 에폭시 DoE, 보이드·언더필 관찰, KPI 검증, 열압착), 공정 물리 모델로 예측한 DoE 결과표, 다이 크기별 하중 상한, 평행도 레벨링 절차, 3단 안전 계층과 표준 운전 절차를 제시했다(4, 13장).

**한계.** 모든 결과는 계산·시뮬레이션이다. 다이 미끄러짐과 바닥 진동 진폭은 모델 없이 예산값을 썼고, 툴–척 평행도는 제작 후 측정 항목이다(12장). 질량(약 101 kg)과 높이(630 mm)는 원문 기준이 없어 참고값으로만 기록했다.
