# 14. 결론 (Conclusion)

**중간 대비 바뀐 점**

- 중간의 설계 원칙과 교육적 목적을 적층 본더로 확장했다.
- 원문 KPI와 기말 설계 목표의 판정 범위를 분리했다.
- 냉각·접합 온도·보이드·휨 모델의 미해결 한계를 명시했다.
- 실물 bring-up과 제작 후 검증을 후속 과제로 정리했다.

## 14.1 요약과 원문 KPI

중간의 교육용 데스크톱 다이본더를 다단 적층 본더로 확장하고, TC-NCF와 MR-MUF의 열 이력·정렬·휨·충전·사이클을 비교하는 시뮬레이터를 구성했다. 중간의 대칭 프레임·조동/미동 스테이지·듀얼 비전·열 격리 설계는 유지하고, 적층 척·리플로우 척·가압 지그·공통 C 펌웨어를 추가했다. 공개되지 않은 업체 공정 조건은 가정값이며 두 공정의 산업적 우열을 판정하지 않는다.

**원문 KPI·원문 요구 판정표.** 아래 통과는 계산·소프트웨어 모의 검증 범위다. 실물 제작·정밀도 인증을 완료한 결과가 아니다. 입력의 설계 목표·가정값과 계산 결과는 각 근거 파일에서 구분한다.

| 원문 항목 | 원문 기준 | 근거와 설계 결과 | 충족 여부·해당 범위 |

## 14.3 설계와 교육에서 얻은 것

**광학 정합과 본딩 정합은 다르다.** 중간 통합 오차 예산에서 남는 큰 항목은 열드리프트·Z 비반복·접촉 미끄러짐이다. 기말의 작은 비전 잔여값은 이 항목들을 대신하지 않는다. 고정 정렬 온도와 도달 후 90 s 안정화 절차를 유지하고, 리플로우 기준점 이동은 완성 스택의 강체 동반 이동 해석으로 층간 상대 정합과 구분했다(`calc/hardware/thermal_expansion.json`). 실제 열 휨과 미끄러짐은 측정해야 한다.

**하중 경로와 공정 물리가 장비 사양을 정한다.** 중간의 비대칭 외팔 구조를 대칭 지지로 바꾼 원칙을 유지하고, 기말에는 다이 전면 지지·범프별 하중 전달까지 확인했다. 피드백을 C로 옮기면서 포화·적분 누적·능력을 넘는 램프를 다뤘다. 끼워맞춤도 조립 여유·정밀 위치·고정 다웰의 역할에 맞춰 구분한다(8·10·11장).

**모델이 설명하는 것과 설명하지 못하는 것을 함께 배운다.** 실습 A~E는 열 이력, 층 수, 정렬과 자기정렬, 스퀴즈와 가압 충전, 알람 복구를 비교한다. 중간 DoE는 에폭시 기초 실습으로 살리고, MR-MUF는 모세관 단독에서 압력 구동 충전으로 확장했다. 상세 조작은 `docs/manual/실습매뉴얼.md`, 교육·안전은 13장, 공정 비교는 15장을 따른다.

## 14.4 남은 한계와 제작 후 시험

- **냉각 FAIL/REVIEW:** 유량 100 L/min·h=400 W/m²K는 실측 전 가정이다. 노즐·탑재물·열접촉을 반영한 실제 피크→180 ℃ 프로파일로 목표를 다시 확인해야 한다(`calc/hardware/README.md`).
- **보이드 정량 모델 부재:** NCF는 접촉·겔화·저점도 체류의 정성 경향만 제시한다. MR은 미충전률을 계산하지만 갇힌 기포·필러 여과·경화 중 점도 상승을 정량화하지 않는다. `null`은 0 %가 아니다(15장 15.4~15.5절).
- **S3 휨 모델 한계:** 1D 선형 탄성·상온 물성, 기판 구속·점탄성·경화 수축 미포함으로 업체의 박형 다이 휨 우열 주장을 재현하지 못한다. 업체 주장은 출처를 붙인 관찰 항목이며 판정 입력이 아니다(15장 15.9절).
- **열·제어 결합 한계:** 스택 열 모델의 헤드 경계는 이상 추종이며 실제 400 W 제한·wasm 폐루프와 완전히 결합하지 않았다. 기본 TC-NCF 자기 접합 온도 미달은 남겨 두고 보정 옵션과 거부 조건을 제공한다(`docs/stage3_report.md`, `stage4_model_update.md`).
- **실물 bring-up 범위 밖:** MCU 빌드 성공은 센서·서보·PWM 실구동을 뜻하지 않는다. PG0 외 15개 신호는 배선 설계값이며 독립 안전 회로·실제 피드백 지연을 시험하지 않았다(`firmware/README.md`, `wiring/pinmap.csv`).

**제작 후 우선 시험.**

1. 건식 반복 배치로 본딩 후 X·Y 3σ를 측정하고 접촉 전·후 미끄러짐을 분리한다.
2. 툴–척 평행도·고온 평면도·열드리프트·가이드 비반복을 측정해 오차 예산을 갱신한다.
3. 실제 범프 접촉 불균일·박형 다이 표면 결함·전면 석영 지지와 하중 전달을 확인한다.
4. 지그 기밀·예압·유리/나사 내압·벤트 트랩과 수지 누설을 시험한다.
5. 리플로우 승온·냉각·층별 접합 온도, 고온 경고등·배기 후드를 확인한다.
6. 센서·PWM·서보 HAL을 구현하고 과하중·과온·비상정지·도어·냉각 유량의 독립 차단과 수동 복귀를 검증한다.
