# 요약

본 설계는 중간 과제의 교육용 데스크톱 다이본더를 **HBM 방식 다단 적층 본더**로 확장하고, 한 장비에서 **TC-NCF와 MR-MUF의 원리 차이**를 관찰하는 디지털 트윈을 구현했다. 양산 공정의 우열 판정이 목적은 아니다. 업체가 공개하지 않은 세부 공정 조건은 교육용 가정으로 두고 문헌값·설계값·역산 추정값·관찰 항목과 구분했다.

장비는 고정 헤드·이동 기판, 조동+미동 스테이지, 듀얼 비전, 펄스 히터와 리플로우 척으로 구성한다. 공통 C 제어기를 PC·MCU·wasm으로 빌드하고 JS 공정 모델, Worker, 웹 HMI·3D 뷰로 연결한다. 헤드 400 W와 척 150 W는 설계값이며 동시 통전을 차단한다.

| 원문 KPI·요구 | 목표 | 설계·계산·검증 근거 |
|---|---|---|
| 정합 반복정밀도 | ±1 μm | 중간 RSS 3σ 0.88 μm; 실물 반복 시험 필요 |
| 펄스 히터 최고 온도 | 400 ℃ | 중간 도달·유지 모델; 보정 필요 헤드가 400 ℃ 초과 시 거부 |
| 최대 본딩 하중 | 50 N | 중간 설계 범위 유지, TC 기본 40 N은 별도 설계값 |
| 풋프린트 가로·세로 | ≤ 600 mm | Fusion 외곽 590×480 mm, 간섭 0 |
| 피드백 주기 (원문 요구) | 10 ms | 하중 1 ms·온도 10 ms 공통 C 구현 |

핵심 시나리오는 저장된 단계 4 결과를 사용했다(15장).

| 장면 | 핵심 결과 (계산 결과·관찰값) |
|---|---|
| S1 열 이력 | TC 기본 1·2층 208.5/215.8 ℃로 액상선 221 ℃ 미달; 헤드 보정 약 231 ℃, MR 약 250 ℃ |
| S2 정렬 | 동일 시드 12단 누적 x,y: TC (0.24, −1.16) μm / MR (0.041, 0.012) μm; 누적 단일 표본은 판정 없음 |

PC↔wasm SIL은 14,400 출력값 비교에서 최대 절대 차이 8.1e-6으로 통과했다. HMI는 레시피 차단·모델 알람·고장 주입·수동 리셋을 제공하며 Node 24 테스트 후 Pages로 배포한다. 데모: https://ycpark06.github.io/hbm-stacking-edu-sim/web/

**한계:** 실물 검증이 아니며 접촉 열저항·입구 압력에 민감하다. 휨의 기판 구속·점탄성·경화 수축, NCF 보이드 정량 모델과 MUF 기포 포획은 미포함이다. 스택 열 경계와 출력 제한 제어기는 직접 결합하지 않았다. 냉각은 피크→180 ℃에서 4 K/s 이상 유지 목표에 최소 3.39 K/s로 FAIL/REVIEW다. 기밀·내압·열프로파일은 제작 후 시험해야 한다. 업체 주장은 관찰 항목이며 판정하지 않았다.
