# 5. 정합 오차 예산 (Alignment Error Budget)

**중간 대비 바뀐 점**

- 중간 RSS 3σ 0.88 μm와 오차 배분·보정 방법을 유지했다.
- 직전 층·기판 기준 누적의 차이와 12단 3.06 / 0.88 μm를 구분했다.
- 기판 기준의 인접 층 √2 성분과 MR 자기정렬 잔여의 통계 한계를 추가했다.
- 108.6 μm 기준점 공통 이동과 고정 정렬 온도·90 s 안정화 절차를 설명했다.

## 5.1 목적과 방법

원문 KPI ±1 μm를 "X·Y 각 3σ ≤ 1 μm"로 해석한 장비 반복정밀도 목표를 달성하려면 오차를 만드는 각 요인에 허용치를 나눠 줘야 한다. 이렇게 나눈 허용치가 6~10장의 구동부·열·구조·비전·제어 설계 목표가 된다. 그래서 이 장은 이후 계산의 기준표 역할을 한다.

- **대상:** 광학 정렬이 끝난 순간이 아니라 본딩을 마친 뒤 측정한 다이 중심의 배치 오차. 측정은 2장의 KPI 검증 모드(유리 테스트 다이, 건식 배치) 조건을 따른다.
- **축:** X와 Y는 구조가 대칭이므로 같은 예산을 적용한다. 각도는 5.4절에서 따로 다룬다.
- **합산:** 항목들이 서로 독립이라고 보고 분산을 더한다(RSS, σ_total = √Σσᵢ²). 정규분포가 아닌 항목(균일분포)이 섞여 있으므로 중간 계산의 몬테카를로 100만 회로 실제 분포의 99.73 % 구간도 확인했다.
- **보정 가능한 성분:** 매번 같은 크기로 나타나는 계통 오차(가이드 진직도 형상, 정상상태 열변형, 하중에 비례하는 처짐)는 보정표로 제거한다. 예산에는 보정 후 남는 잔차만 넣는다.

몬테카를로 결과(σ = 0.294 μm, 99.73 % 구간 ±0.86 μm)는 RSS 계산과 일치한다. 균일분포 항목이 섞여 있어 분포 꼬리가 정규분포보다 조금 짧고, 그래서 99.73 % 구간이 3σ보다 약간 좁다.

**상위 세 항목이 전체 분산의 59 %를 차지한다.** 열드리프트(26 %), 다이 미끄러짐(17 %), Z 하강 변위(17 %)다. 셋 다 "정렬이 끝난 뒤 접촉할 때까지" 생기는 오차다. 비전 성능을 아무리 높여도 이 구간을 관리하지 못하면 KPI를 달성할 수 없다. 이것이 PBL 9쪽의 "광학 정합 정밀도"와 실제 배치 정밀도가 다른 이유다.

## 5.3 민감도: 무엇이 KPI를 깨는가

| 시나리오 | 바뀐 항목 | 3σ (μm) | 판정 |
|---|---|---|---|
| 기준 설계 | — | 0.88 | 통과 |
| 열드리프트 2배 | #6 σ 0.15 → 0.30 | 1.18 | **실패** |
| 다이 미끄러짐 2배 | #8 σ 0.12 → 0.24 | 1.08 | **실패** |
| 광학 오프셋을 매일 보정하지 않음 | #3 σ 0.10 → 0.30 | 1.22 | **실패** |
| 미동 스테이지 없이 조동만 사용 (v1 설계, ±0.5 μm) | #2·#4 → σ 0.29 | 1.49 | **실패** |

어느 한 항목만 두 배가 되어도 KPI를 넘는다. 특히 미동 스테이지 없는 단일 스테이지(v1 설계)는 1.49 μm로 실패한다. 이것이 3장에서 조동+미동 2단 구조로 바꾼 정량 근거다. 매일 하는 광학 오프셋 보정도 선택 사항이 아니라 필수 절차다.

## 5.4 각도 예산

각도는 원문 KPI가 아니라 설계 목표 ±0.005° (3σ)로 둔다(2장 2.4절). 피듀셜 두 개(간격 4 mm, 5×5 mm 테스트 다이)를 한 프레임만 찍으면 비전만으로 σ 0.002°가 나와 예산을 혼자 다 쓴다. 그래서 각도는 네 모서리 피듀셜과 4프레임 평균으로 측정한다. 이렇게 하면 비전 오차가 σ 0.0005°로 줄어든다.

| 항목 | 1σ (°) |
|---|---|
| 비전 (4 피듀셜 × 4프레임 평균) | 0.0005 |
| 정렬 수렴 잔차 (Δθ ≤ 0.002°, 균일) | 0.0012 |
| θ 스테이지 위치결정 | 0.0003 |
| 접촉 시 회전 미끄러짐 | 0.0008 |
| **합계** | **0.0015 → 3σ 0.0046° (통과)** |

10×10 mm 다이의 모서리(중심에서 7.1 mm)에서 0.005°는 0.62 μm 변위다. 중심 위치 오차와 합쳐도 모서리 범프가 2 μm 안에 들어온다.

## 5.6 측정 방법과 한계

KPI 검증 모드에서 본딩 후 오차를 측정하는 도구도 같은 듀얼 비전이다. 그래서 측정값에는 비전 오차(#1)와 광학 오프셋(#3)이 다시 들어간다. 이를 분리하기 위해 두 가지를 한다.

1. 처음 몇 개 시편은 외부 측정 현미경이나 좌표측정기로 교차 검증한다.
2. 시편을 180° 돌려 다시 측정하는 반전법으로 광학 오프셋을 상쇄한다.

에폭시 다이 부착에서는 경화 중 다이가 접착제 위에서 떠 움직이며, 이것이 장비 오차보다 클 수 있다(팬아웃 공정의 die shift 개념, 플립칩·WLP 강의 92쪽). 이 이동량은 장비 KPI에 넣지 않는다. 대신 관찰 모드에서 경화 전·후 오프셋 차이로 측정하는 실습 항목으로 쓴다.

*중간 계승 수치·구분: 5.1~5.6절 배분·가이드·각도·열·진동·접촉 수치는 설계 목표와 가정이며, 출처는 `docs/report/midterm/05_정합오차예산.md`, `calc/midterm/error_budget.py`·`error_budget.json`이다. RSS·MC·민감도·각도 합계는 해당 입력의 계산 결과다. 저레인지 램프 변경은 `firmware/README.md`를 따른다. 이 결과는 실물 반복정밀도 검증 완료를 뜻하지 않는다.*

## 5.7 다단 적층의 정렬 기준과 누적 오차

기말 적층 모델의 기본 σ는 중간 RSS 0.294 μm, 3σ=0.88 μm를 유지한다(`sim/params.json:alignment.sigma_layer_um`, `calc/midterm/error_budget.json`). 기존 혼합분포를 적층 모델에서는 축별 독립 정규분포로 근사한다. N은 기판 위 배치 횟수이며, 맨 아래 기준 기판은 다이 층 수에 넣지 않는다.

- **직전 층 기준:** x_i=x_{i−1}+ε_i이므로 맨 위↔기판 σ_top=σ√N. 인접 층 오차 σ는 일정하다.
- **기판 기준:** x_i=ε_i로 각각 독립 배치하므로 맨 위↔기판 σ_top=σ다. 다만 인접 다이 차이 ε_i−ε_{i−1}의 σ는 √2σ다. 이 인접 차이들은 서로 독립이 아니다.

| 배치 수 N | 직전 층 기준 top↔기판 기대 3σ μm | 기판 기준 top↔기판 기대 3σ μm |
|---|---|---|
| 2 | 1.25 | 0.88 |
| 4 | 1.76 | 0.88 |
| 8 | 2.50 | 0.88 |
| 12 | 3.06 | 0.88 (약 0.88) |

*표는 계산 결과: `docs/tcncf_mode_report.md` 누적 정렬 절, `sim/test/c2_results.json`의 해석값·시드 MC, `sim/alignment.js:stackOffsetExpected`. 입력 σ는 중간 설계 예산이며 누적 오차는 판정 없는 관찰 항목이다.*

**해석상 주의.** “기판 기준이면 0.88 μm 유지”는 top↔기판 위치를 뜻한다. 인접 층 3σ는 약 1.25 μm로 층간 설계 목표를 자동 만족하지 않는다. 반대로 직전 층 기준은 인접 층 0.88 μm를 유지하면서도 top↔기판은 약 3.06 μm까지 누적된다. 맨 위↔첫 다이의 σ는 직전 층 기준 σ√(N−1), 기판 기준 √2σ로 별도다. 공통 열드리프트나 미끄러짐 상관이 있으면 독립 RSS·√N 근사도 다시 검토해야 한다. 누적 표본 한 개와 층간 반복정밀도 3σ를 같은 판정으로 읽지 않는다(`docs/tcncf_mode_report.md`).

## 5.8 MR-MUF 자기정렬 후 잔여 오차

TC-NCF는 배치 오차를 그대로 남기며 MR-MUF는 4장 4.13절의 강성·감쇠·마찰 응답을 각 층 액상선 위 시간 동안 적용한다. 같은 시드 초기 오차를 사용하는 S2의 최대 층간 축 3σ는 TC-NCF 0.88 μm, MR-MUF 0.053 μm다(계산 결과, `docs/stage4_model_update.md` S2, `sim/test/stage4_results.json`). 최종 누적 좌표와 전체 결과는 **15장 15.6절**에 둔다.

MR 잔여 3σ는 가정한 감쇠·정지 마찰 아래 기존 20000 표본 MC의 표준편차 지표다(`README.md` 3.3절, `docs/stage3_report.md`). 마찰로 비정규 분포가 될 수 있어 이를 99.7 % 포함 보증이나 실물 정합 인증으로 쓰지 않는다. 가접 구속이 강하거나 액상 시간이 짧으면 보정 효과는 달라진다. 잔여 오차를 중간 RSS에서 임의 차감해 새 장비 예산으로 만들지 않는다.

## 5.9 리플로우 열팽창과 정렬 절차

20→250 ℃의 균일 가열 손계산에서 척 기준점은 **108.56 μm(약 108.6 μm)** 움직인다(계산 결과, `calc/hardware/thermal_expansion.json:results.datum_shift_um`). 이 값은 원문 정합 KPI보다 크지만 **완성 스택이 척과 함께 강체 이동**한다는 해석에서 모든 층에 공통인 절대 좌표 이동이다. 층 사이 상대 위치는 바뀌지 않으므로 층간 정합 ±1 μm 적용에 영향이 없다. 공통 계통 이동을 무작위 RSS에 제곱 합산하지 않는다.

절차는 **상온 또는 고정 정렬 온도에서 각 층 정렬 완료 → 정렬 온도 고정 → 온도 도달 후 90 s 안정화 → 정렬·접촉**이다. 적층 척=리플로우 척 구성도 이 규칙을 따른다. 냉간 좌표를 고온에 그대로 쓰는 이전 오용 상한 `uncorrected_total_bound_um`은 보존용 비교값이며 층간 정합 판정에 쓰지 않는다(`calc/hardware/thermal_expansion.json`, `calc/hardware/README.md`).

강체 동반 이동 해석은 열 휨·미끄러짐·층간 CTE 차이를 없애는 결론이 아니다. 고온 평면도와 실제 열안정은 제작 후 확인한다. 90 s는 중간 헤드 안정화 계산을 계승한 확정 운전 절차이며 신규 척의 실제 평형 도달 시간을 실증한 값은 아니다.


정밀값은 `sim/params.json:alignment.sigma_layer_um`, `sim/test/stage4_results.json:representative[id=S2].results[].alignment` 및 `docs/tcncf_mode_report.md`의 층수별 계산표에 보존되어 있다.
