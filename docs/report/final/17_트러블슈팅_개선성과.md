# 17. 트러블슈팅 과정과 개선 성과

## 17.1 작업 방식(Codex 작성·Claude 검증·PR)

계획과 완료 기준을 정한 뒤 기능별 브랜치·worktree를 만들고 Codex가 코드·문서를 작성했다. Claude는 폴더 구조, 테스트와 golden 일치, 원문 KPI·설계 목표·가정값 표기 및 완료 기준을 검증했다. 검증 실패 시 증상→원인 분석→해결→결과 순서로 Issue를 남기고 수정·재검증했다. 검증을 통과한 변경은 Claude가 PR을 작성하고 리뷰 결과와 반영 이력을 남겨 병합하는 흐름이다. 작성·검증 역할 분리는 `CLAUDE.md` 4절과 `docs/PLAN.md` 11절의 규칙이다.

독립 작업은 worktree로 병렬 진행하고 담당 경로를 제한했다. 보고서도 장별 원고와 공통 빌드 작업을 나누어 충돌을 줄였다. 다만 worktree의 `.git`은 공유 메타데이터이므로 샌드박스에서 index.lock 생성이 실패했다(Issue #23). 이에 Codex는 허용 경로의 파일 작성과 검증을 맡고 커밋·PR은 Claude가 수행하도록 분리했다. 이 원고 작성 작업에서는 커밋·push·PR·Issue 쓰기를 수행하지 않았다.

정량 성과는 해당 테스트 입력에서의 계산·검증 결과다. SIL 일치는 물리 모델의 정확도를 보증하지 않고, 모델의 양호 판정도 실물 제작·양산 검증을 뜻하지 않는다. CAD 외곽은 원문 KPI 확인값이지만 높이 630 mm·질량 101.88 kg은 참고값이다.

## 17.4 남은 과제

1. **실물 검증:** 보드 bring-up, 센서·구동기 HAL, 접촉 열저항과 MUF 입구 유효 압력 실측, 기밀·내압·열프로파일 시험이 필요하다. 손계산 PASS는 시험 완료가 아니다.
2. **냉각:** 피크→180 ℃에서4 K/s 이상 유지 설계 목표에 최소3.39/평균4.10 K/s로 FAIL/REVIEW다. 180 ℃ 아래는 관찰 항목이다. 풍량100 L/min·h=400 W/m²K는 가정값이므로 노즐·유량·열전달계수와 탑재 조건을 시험해야 한다.
3. **공정 모델:** 휨의 기판 구속·점탄성·경화 수축, NCF 보이드 정량화, MUF 투과도·필러 여과·기포 포획, 출력 제한을 포함한 스택 열–제어 결합이 남아 있다. S3의 업체 주장 미재현과 기본 TC 1·2층 접합 온도 미달을 최종 결과에도 유지한다.
4. **제출물 통합:** 다른 담당 장과 실습 매뉴얼을 병합하고 HMI 화면 캡처, 전체 PDF 쪽수·표·도면 시각 검토를 완료한다. 음성 설명 영상과 발표 자료는 이후 단계이며 `v2.0-final` 태그는 단계8 최종 제출 시 사용자 결정에 따른다.
