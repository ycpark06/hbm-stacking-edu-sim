# 설계 보고서

- [중간 보고서](midterm/): `v1.0-midterm` 기준 원고·그림·계산 및 기존 PDF 빌드. 기준점으로 보존한다.
- [기말 보고서](final/): 적층 본더 개정 00~17장, 신규 공정 모델·디지털 트윈·트러블슈팅·개선 성과, 그림과 PDF 빌드. 누락 장은 경고 후 건너뛴다.
- [실습 매뉴얼](../manual/실습매뉴얼.md): 적층 모드 비교와 알람 대응 실습.

기말 빌드는 `cd docs/report/final && python3 build_final.py`로 실행한다. 환경·그림 생성·검증 절차는 [기말 안내](final/README.md)를 따른다. 중간 원본과 개인정보가 포함된 외부 제출본은 수정하거나 복사하지 않는다.
