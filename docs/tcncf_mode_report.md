# 단계 3-C2 — TC-NCF 점도·유동·정렬·사이클

브랜치 `feat/tcncf-mode`. 원문 KPI는 ±1 μm, 400 ℃, 50 N, 풋프린트 ≤600 mm, 피드백 10 ms이며 이 보고의 층별 3σ 목표 1 μm는 설계 목표다. 문헌 처리량은 비교값, 새 모델 계수와 미공개 취급 시간은 가정값이다. 기존 params 항목은 메타데이터까지 변경하지 않았다. 결과에 맞춘 피팅은 하지 않았다.

## 모델·입력과 경계

`ncfViscosity(T_C, alpha, params)`는 μ=μmin exp[(Eμ/R)(1/T−1/Tref)]·[αg/(αg−α)]^(A+Bα)다. 온도는 K, 활성화에너지는 J/mol로 환산한다. α=0에서 원본 Arrhenius식과 일치하고 α≥αg이면 Infinity(유동 정지)다. μmin=1727 Pa·s와 Tref=138 ℃는 기존 문헌 기준점이다. Arrhenius 항은 기준점 위에서 더 낮아질 수 있으므로 이 값을 온도 전체의 하한으로 clamp하지 않는다. 실제 최소점은 승온과 경화 이력의 결합으로 결정된다. 서로 다른 공개 NCF 재료의 값을 조합한 대리 모델이며 특정 양산 재료의 실측 곡선은 아니다.

경화는 원본 `cureRate`의 1차식 dα/dt=k(T)(1−α)를 유지한다. 141 ℃ 미만에서는 반응률 0, 기준 250 ℃에서 3 s 후 αg=0.6이 되도록 기준점을 지정한다. NCF의 활성화에너지 60 kJ/mol, αg=0.6, Castro 계수 A=2/B=0은 가정이다. `cureStep`은 일정 온도에서 정확한 지수해를 제공한다. 이력 결합은 누적 반응량 H=∫k(T)dt, α=1−exp(−H)로 수행하고, 선형 온도 구간의 onset 교차를 나눈 뒤 RK4 가중치로 적분한다. 0.005 s 경화 기록 사이 H를 선형 보간한다. 각 필름은 새 층 추가 시 α=0이며 후속 층 접합 재가열 중에도 경화를 누적한다.

`squeezeIntegrate`는 원본 Stefan `squeezeDhdt`를 y=1/h²로 대수 변환한 뒤 RK4로 적분한다. y′=−2 h⁻³·squeezeDhdt이므로 상태 의존성이 없어져 h³ 강성을 피하면서 같은 방정식을 푼다. 일정 하중·점도에서는 정확한 선형 y 해가 되며, 접촉은 부분 RK4 스텝의 52회 이분법으로 찾는다. 시간 의존 F와 μ를 그대로 받으며 무한 점도는 유동 0이다. 반환값은 h(t), contact_time_s(null은 미접촉), remaining_thickness_m, gel_time_s, gel_before_contact다. 일반 적분기는 gel_time_s를 선택적으로 받으며, 스택 어댑터는 경화 이력에서 계산해 전달한다.

**초기 필름 두께 해석 차이:** 이번 사용자 지시의 곱셈을 따라 h0=`ncf.film_thickness_over_gap.value`×gap=4×15=60 μm로 두었다. 기존 항목은 단위 um, “gap+4 μm”라는 가산 정의(19 μm)다. 해당 항목을 바꾸지 않고 새 `ncf.film_initialization` 가정에 이번 숫자 배수 해석을 명시했다. 따라서 60 μm를 기존 문헌이 직접 제시한 NCF 두께라고 해석하면 안 된다.

접촉 간격 h_stop은 `interlayer_gap`(15 μm)을 유효 접합 후 standoff로 사용한다. 기본 pillar 9+cap 6=15 μm와 같다. gap을 바꾸면 기존 pillar/cap을 자동 보정하지 않으므로 결과의 contact_gap_m와 bump_height_m가 다를 수 있다. 접촉 뒤 h는 고정하며 범프 변형·하중 분담·접촉 후 squeeze-out을 풀지 않는다. 남은 두께는 두 표면 사이 필름 간격이며 필렛 체적을 포함한 전체 수지 잔량이 아니다.

하중은 새 층 자기 접합의 ramp/hold 동안 기존 설계값 40 N, 냉각 시작부터 0 N이다. C1 `stackSim`의 새 층 절점 온도를 사용한다. C1은 충전층 독립 온도 없이 다이 중심 절점에 열용량을 합치므로 **충전층 온도의 대리값**이다. 열이력은 h 변화·경화 발열·점탄성에 되먹임하지 않는 단방향 결합이다. 열 해석의 ramp/hold/cool 앞에 취급 시간을 더하는 사이클 회계 모델이므로 정렬/접근 중 추가 경화는 이 열이력에 포함되지 않는다.

**보이드 경향은 정량 모델 아님.** 함수 주석과 모든 tendency 결과에 `quantitative:false`를 명시한다. 결함 면적률(%)은 생성하지 않는다. 접촉 전 겔화 또는 공정 종료까지 미접촉이면 미접합 위험, 접촉 전 μ≤2μmin인 시간이 1 s 미만이거나 접촉 점도가 2μmin보다 높으면 기포 주의, 그 외 낮은 경향이다. “낮은 경향”은 무결함 판정이 아니다. 실제 온도×경화 이력에 의해 저점도 체류시간이 달라진다. 장비 20 K/s는 문헌 80 ℃/s의 1/4이며 느린 승온은 유동 시간과 조기 경화 모두를 늘릴 수 있어 속도만으로 결함률 순서를 정하지 않는다. 문헌 80은 비교 표시에만 사용하며 기본 열이력은 20을 유지한다.

## 누적 정렬 오차: 해석값·시드 Monte Carlo

`stackOffset({N,sigma_layer_um,reference,rng,params})`에서 N은 기판 위 배치 횟수이고 기판이 맨 아래 기준이다. σ 생략 시 명시적으로 전달한 params의 `alignment.sigma_layer_um`을 읽는다. 중간 오차 예산 RSS σ=0.29416548630546946 μm(3σ=0.8824964589164084 μm)을 사용한다. 각 축의 오차를 독립 정규분포로 근사하며 TC-NCF 자기정렬은 없다. 이전 층 기준은 ε를 누적하므로 top↔substrate σ=σ√N, 기판 기준은 각 위치가 독립이므로 σ가 N과 무관하다. 기판 기준에서는 인접 다이 오차 σ=√2σ이며 이 인접 오차들이 서로 독립이라는 뜻은 아니다. 결과의 layer_errors_um은 실제 인접 위치 차이다. **top↔첫 다이**를 원하면 별도 top_to_first_die_sigma_um을 사용한다: previous는 σ√(N−1), substrate는 √2σ(N>1), N=1은 0이다.

아래 표는 top↔substrate의 축별 σ이며 반경 오차나 최대 오차가 아니다. 시드 489, 표본 20000회. 표본 σ의 상대 표준오차는 1/√(2(M−1))≈0.5000%, 테스트 허용은 5배(약 2.5001%)다. 평균도 5σ/√M 범위로 확인했다. 이는 모델의 정규·독립 가정 아래 검증이며 공통 열드리프트/회전·미끄러짐 상관을 별도로 추정하지 않는다.

## 사이클 시간 분해와 처리량 비교

`trapezoidMoveTime(d,v,a)`는 d≥v²/a에서 d/v+v/a, 나머지에서 2√(d/a)다. `bondStepTimes(mode,{params,...recipe},machine)`과 `stackCycleTime(mode,N,recipe,machine)`은 브라우저에서도 파일 API 없이 호출한다. machine은 params.cycle 키 이름으로 수치 override를 받고 recipe.xy_distance_mm/z_distance_mm/mold_fill_s를 지원한다. C3의 계산 충전 시간을 mold_fill_s로 전달하면 아래 기본 10 s 충전 대기를 대체한다.

층별 시간은 병렬 중첩 없이 합산한다. TC-NCF는 픽업·XY 이동·Z 이동·정렬·접근·20 K/s 승온·유지·냉각, MR-MUF는 픽업·이동·정렬·접근·tack 뒤 전체 스택에 리플로우·공급·충전·경화 1회다. 초기 헤드 예열/정렬 안정화 대기, 배치 오븐 여러 스택 동시 처리, 금형 예열·경화 뒤 별도 냉각/이송은 포함하지 않는다. 기존 3 s MR-MUF 층당 시간에는 취급이 포함되어 있으므로 tack에 3 s를 다시 더하지 않는다. 이 3 s는 비교값으로만 남긴다.

## 검증·HANDOFF 차이·남은 한계

실행 명령 `node --test sim/test`: tests 134, pass 134, fail 0, cancelled 0, skipped 0, todo 0. 기존 golden 111개 유지. 이번 추가 5개 테스트는 점도·경화, 스퀴즈, MC, 사이클, 결합 시나리오의 묶음이다. `git diff --check` 통과.

일정 점도에서 RK4 두께/접촉 시간과 원본 squeezeBlt/squeezeTimeTo 상대 1e-10, 하중 2배→접촉 시간 1/2 상대 1e-6 이내를 확인했다. 시간 의존 점도 μ(t)=μ0 exp(t)인 매끄러운 검증 문제에서 dt 절반의 오차 감소비는 15~17(4차)로 검사했다. 겔 정지·입력 경계·온도 onset과 250 ℃ 겔 시간 정규화, MC 평균/분산의 표본수 기반 허용구간, 사다리꼴 경계 연속성, C1 오븐 시간 일치, C3 fill override도 검증했다.

결합 모델에서 12층/50 μm의 유동·경화 dt만 0.005→0.0025 s로 줄였을 때 최대 접촉 시간 차는 9.32e-07 s, 남은 두께 차 최대 0 μm다. C1 열이력은 고정했으므로 이 검사는 열 해석 시간 간격의 수렴 검증을 대체하지 않는다. 전체 차이는 JSON convergence에 기록했다.

HANDOFF와 구현 차이: 파일 접근 없이 브라우저 import를 유지하려고 새 기본값 함수에 params를 명시 전달한다. Stefan식은 수치적으로 안정적인 y=1/h² 상태로 RK4 적분했다. 기판/첫 다이 기준의 N 대 N−1 차이를 별도 결과 필드로 명확히 했다. 필름 두께는 이번 사용자 곱셈 지시가 기존 가산 정의보다 우선한다. 보이드는 허용된 정성 등급을 선택하여 면적률을 생성하지 않는다.
