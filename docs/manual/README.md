# 실습 매뉴얼·안전

[실습매뉴얼.md](실습매뉴얼.md)은 실물 장비 없이 웹 시뮬레이터로 실습하는 학생을 위한 문서다.

| 구성 | 내용 |
|---|---|
| 1장 머리말 | 목표, 접속·화면 안내, 수치 구분 배지, 공통 입력 |
| 2~6장 실습 A~E | 열 이력, 층 수, 정렬·자기정렬, 보이드 원인, 알람 대응 |
| 7장 안전 | 실물 운전을 가정한 수칙, 일일 인터락 확인 절차 |
| 부록 A·B | 개인정보 없는 제출 양식, 용어 |

각 실습에는 목적·준비 설정·번호 절차·빈 기록표·확인 질문·예상 결과·해석·모델 한계가 있다. 예상 결과는 저장소의 현재 결과 JSON에서 옮겼으며, 출처 파일과 키를 해당 절에 표시했다. 단계 3 수치를 현재 예상 결과로 혼용하지 않는다.

- 웹: <https://ycpark06.github.io/hbm-stacking-edu-sim/web/>
- 로컬 실행: 저장소 루트에서 `web/serve_local.sh`, 표시되는 `/web/` 주소로 접속
- 계획·판정 기준: [PLAN 9절](../PLAN.md#9-교육안전), [요구사항](../requirements.md)
- 입력·결과: [params](../../sim/params.json), [현재 조합 결과](../../sim/test/scenario_results.json), [대표 장면](../../sim/test/stage4_results.json), [접합 온도 보정 결과](../../sim/test/bond_temp_results.json)
- 안전 근거: [중간 보고서 13장](../report/midterm/13_교육안전.md), [하드웨어 계산·잔여 검토](../../calc/hardware/README.md), [펌웨어 인터락 계약](../../firmware/README.md)

NCF 필름 두께·접촉 시간은 웹 편집 항목이 아니다. 실습 D는 웹으로 바꿀 수 있는 간격·입구 압력과 파일에서 읽는 항목을 구분한다. 안전 절차의 웹 연습은 실물 시험을 대신하지 않는다. 기말 보고서 13장에서 이 매뉴얼을 참조한다.
