# 교육용 HBM 적층 본더 실습 매뉴얼

목차: 1장 머리말 → 2장 실습 A 열 이력 → 3장 실습 B 층 수 → 4장 실습 C 정렬 → 5장 실습 D 보이드 원인 → 6장 실습 E 알람 → 7장 안전·일일 인터락 확인 → 부록 A 제출 양식·B 용어.

## 1. 머리말

### 1.1 실습 목표와 범위

이 실습은 학생이 TC-NCF와 MR-MUF의 **원리 차이를 체험**하는 과정이다. TC-NCF는 필름을 사이에 두고 층마다 열과 하중으로 접합한다. MR-MUF는 층마다 임시 고정하고 전체를 리플로우한 뒤 수지를 충전한다. 열 이력·정렬·휨·충전·사이클을 비교하되 공정 또는 업체의 우열을 판정하지 않는다.

실물 장비는 사용하지 않는다. 계산 결과와 합성 영상으로 관찰하고, 7장의 실물 운전 가정 안전 절차를 웹에서 연습한다. 공정 조건은 **교육용 가정값을 포함한 조합**이며 업체의 실제 레시피가 아니다. 업체는 세부 조건을 공개하지 않았다. 개별 문헌값·설계값·역산 추정값은 해당 구분을 유지한다.

### 1.2 준비와 화면 구성

브라우저에서 [웹 시뮬레이터](https://ycpark06.github.io/hbm-stacking-edu-sim/web/)에 접속한다. 로컬 실행은 저장소 루트에서 다음 명령을 사용하고, 터미널에 표시되는 주소를 연다.

```sh
web/serve_local.sh
# 기본 접속: http://localhost:8000/web/
```

이 스크립트는 배포용 파일을 조립한 뒤 서버를 실행한다. HTML 파일을 직접 여는 방식은 사용하지 않는다. 초기화 오류가 있으면 오류 문구와 접속 경로를 기록한다. 3D 사용 불가 표시가 나와도 레시피·그래프·알람의 동작 여부는 따로 확인한다.

| 화면 | 학생이 확인할 내용 |
|---|---|
| 레시피·실행 | 층 수·두께·간격·하중·헤드 설정·승온·입구 압력, 보정 옵션을 설정하고 ‘두 모드 비교 실행’ 선택 |
| S1~S5 프리셋 | 저장소에 정의된 대표 조건을 실행. **폼 값을 적용하는 버튼이 아니며 폼을 그 조건으로 갱신하지도 않는다.** 결과 카드 제목의 조건을 기록 |
| 두 모드 결과·비교 | 최대 절대 휨, 판정, 미충전, 누적 정렬, 본더/배치 시간. ‘층별 접합·재가열·재용융’과 ‘사이클 시간 분해’를 펼쳐 확인 |
| 공정 이력·그래프 | ‘그래프 결과 선택’으로 모드·보정 조건을 바꿔 온도·하중·휨·충전·정렬·시간 분해 관찰. 온도 곡선은 층별 범례로 식별 |
| 알람·인터락 | 모델 판정과 별도 wasm 고장 주입 상태 확인. 고장 원인 해제와 수동 래치 리셋은 서로 다른 버튼 |
| 파라미터·근거 배지 | 키·구분·출처 검색. `assumption`, `estimate`, `ncf` 등으로 검색하고 출처 확인 |
| 3D | 적층 진행·헤드 이동의 개략 표현. 휨 과장 배율은 표시 설정이며 계산 입력·실제 변형 크기가 아님 |
| 비전 페이지 | 상단 ‘비전 정렬’ 또는 ‘현재 층 비전 보기’로 이동. 층 번호·시드·보정 단계·모서리 마크를 선택하여 합성 영상 검출 확인 |

진행 화면은 **계산 완료 후 단계 재생**이다. 하중 그래프는 독립 SIL이며 적층 열 모델과 직접 결합한 폐루프가 아니다. 고장 주입은 별도 FIRMWARE 인스턴스이므로 모델 결과 카드가 바뀌지 않아도 고장 시험은 수행될 수 있다.

### 1.3 구분 배지 읽는 법

| 구분 | 읽는 법과 예 |
|---|---|
| 원문 KPI | PBL의 판정 요구: 정합 반복정밀도 ±1 μm, 펄스 히터 최고 400 ℃, 최대 본딩 하중 50 N, 가로·세로 각각 ≤600 mm. 피드백 10 ms는 원문 요구 |
| 설계 목표·설계값 | 과제에서 정한 기준·설정. 층간 축별 3σ ≤1 μm는 설계 목표, 기본 하중 40 N과 보정 여유 10 ℃는 설계값 |
| 문헌값 | 공개 자료에서 가져온 입력. 기본 간격 15 μm, 솔더 액상선 221 ℃ 등. 문헌값 자체가 장비 KPI는 아님 |
| 역산 추정값 | 문헌의 온도차 등을 모델로 역산. 접촉 열저항은 직접 측정값이 아님 |
| 가정값 | 공개 데이터 부족으로 근거를 붙여 정한 입력. 기본 입구 유효 압력 1 MPa 등. `params`에서 근거 확인 |
| 관찰 항목 | 판정 없이 비교: 누적 정렬·사이클·열 이력·업체 주장. 업체 주장은 계산 입력과 합격 근거로 사용하지 않음 |
| 계산 결과 | 위 입력으로 계산한 출력. 실물 측정 또는 성능 보증을 뜻하지 않음 |
| 시연 입력 | 프리셋 조건과 고장 주입 측정값. 예를 들어 주입한 하중은 실물 로드셀 측정값이 아님 |
| 중간 보고서 | 기존 계산·설계에서 가져온 값. 원문 KPI와 구분하고 원래 출처를 확인 |

질량·높이는 **참고값**으로 판정하지 않는다. 배지의 `design`은 목표와 설정을 함께 표시하므로 이 문서와 [요구사항](../requirements.md)에서 용도를 확인한다. 출처의 종류와 결과의 용도를 혼동하지 않는다. 예를 들어 시간은 계산 결과이면서 판정 없는 관찰 항목이다.

### 1.4 공통 준비 설정과 결과 기록

각 실습은 아래 조건으로 시작하고 지정한 항목만 바꾼다. 프리셋은 별도 정의를 실행하므로 결과 카드 조건을 다시 확인한다. 웹의 모드 선택은 비교·진행의 기준이며 실행 결과는 두 모드가 함께 제시된다.

| 웹 입력 | 공통 설정 | 구분·출처 |
|---|---|---|
| 모드 / 층 수 | TC-NCF / 12 | 실습 조건. 웹 기본 층 수 8과 구분 |
| 두께 / 간격 | 100 μm / 15 μm | 두께 설계 목표 / 간격 문헌값 |
| 하중 / 헤드 설정 | 40 N / 300 ℃ | 설계값 / 문헌값을 채택한 시연 설정 |
| 승온 | 20 K/s | 중간 보고서 장비 설정. 문헌 80 ℃/s는 비교값 |
| 입구 압력 | 1 MPa | 가정값. 금형 압력과 다름 |
| SIL 하중 램프 / 저레인지 | 5 N/s / 해제 | 레인지 설계값. 적층 열 모델과 별도 SIL |
| 층별 헤드 설정 온도 보정 | 해제 | 기본 false. 실습 A에서 비교 |

출처: [params](../../sim/params.json)의 `geometry`, `tcncf_process`, `equipment_limits`, `muf`, `recipe`. 동일 시드 비교는 프리셋의 `alignment.mc_seed=489`를 사용한다. 메인 화면에는 시드나 초기 오차를 직접 입력하는 칸이 없다.

예상 결과 표는 저장소 JSON을 옮기고 표시 자릿수만 줄였다. 웹도 유효자리로 표시하므로 끝자리 표기가 다를 수 있다. 구버전 단계 3 결과를 섞지 않는다. 각 실행에서 입력·단위·배지·출처·오류 문구를 함께 적고, 예상과 다르면 조건 차이와 모델 한계를 먼저 확인한다.

## 2. 실습 A — 열 이력 비교

### 2.1 목적

재가열 이벤트와 실제 액상선 통과를 구분하고, 헤드 설정 온도와 다이의 자기 접합 온도가 다름을 확인한다. 헤드 보정으로 접합 온도를 확보할 때의 변화도 관찰한다.

### 2.2 준비 설정

1.4절 공통 설정을 확인한다. **S1 열 이력**은 12단·100 μm·15 μm에서 기본 TC-NCF, 헤드 보정 TC-NCF, MR-MUF를 실행한다. 폼 보정 체크 상태에 의존하지 않는다. 별도 수동 비교에서는 공통 조건에서 보정 옵션만 켜고 ‘두 모드 비교 실행’을 누른다.

### 2.3 절차

1. S1을 실행하고 계산 및 단계 재생 완료를 기다린다. 세 결과의 제목과 보정 여부를 기록한다.
2. 그래프 결과를 순서대로 선택하여 층별 온도 곡선과 액상선 표시를 확인한다. 아래층과 위층의 열 이력을 비교한다.
3. 층별 표를 펼쳐 자기 접합 최고·헤드 설정·재가열·액상선 교차·후속 재용융을 기록한다. 1·2층의 `BOND_TEMP_LOW`와 부족분도 확인한다.
4. 보정 결과에서 자기 접합 최고와 필요 헤드 온도를 확인한다. 기본 헤드 설정을 다이 온도로 대신 적지 않는다.
5. MR-MUF의 가접 노출과 전체 리플로우를 구분한다. 같은 층 수에서 열 이벤트와 용융 횟수의 차이를 설명한다.

자기 접합 최고가 문헌 액상선 **221 ℃ 미만**이면 TC 미달 알람이다. 보정 목표는 액상선+설계 여유 **10 ℃**, 즉 **231 ℃**다. 보정은 층마다 필요한 헤드 설정을 찾고 **400 ℃ 원문 KPI**를 넘으면 레시피를 거부한다. 현재 S1 보정은 수락된다.

재가열은 자체 접합 후의 후속 본딩 이벤트 수이며 용융 여부와 무관하다. 화면의 액상선 교차(`remelt_count`)에는 첫 용융이 포함된다. 후속 재용융(`subsequent_remelts`)은 첫 용융을 제외한다. MR은 전체 리플로우에서 각각 한 번 통과하므로 후속 재용융은 없다.

### 2.7 주의·모델 한계

접촉 열저항은 역산 추정값이며 이상 경계 조건의 열 모델이다. 후경화까지 포함한 실물 전 공정 온도 측정으로 해석하지 않는다. **기본 TC-NCF 1·2층 미달을 삭제하거나 온도를 임의 조정하지 않는다.** 공정 조건에는 가정값이 포함된다. S3 휨은 업체의 박형 우위 주장을 재현하지 못하며 NCF 보이드 정량 모델도 없다. 관련 설명은 3.7절·5.7절을 따른다.

## 3. 실습 B — 층 수 영향

### 3.1 목적

층 수 변화가 열 이벤트·휨 이력·본더 점유 시간에 주는 영향을 확인한다. 전체 공정 최대 휨이 반드시 층 수에 비례하지 않는다는 점을 해석한다.

### 3.2 준비 설정

1.4절 조건에서 보정을 해제하고 두께 100 μm·간격 15 μm를 유지한다. 층 수만 **2 → 4 → 8 → 12**로 바꾼다. 두께 비교는 이후 **S3 박형 다이**, 시간 분해 확인은 **S4 처리량**을 사용한다.

### 3.3 절차

1. 층 수 2를 입력하고 두 모드 비교를 실행한다. 최대 절대 휨·판정·본더 점유·배치 후공정을 기록한다.
2. 층 수만 4, 8, 12 순서로 바꾸어 반복한다. 매번 같은 모드의 결과를 선택하여 층별 휨 그래프도 확인한다.
3. 12단에서 S4를 실행하고 사이클 시간 분해를 펼쳐 후경화와 본더 작업을 구분한다.
4. S3을 실행하여 각 모드의 100 μm와 50 μm 최대 휨·판정·증가 배율을 기록한다.
5. 층 수별 최대값이 같은 이유를 휨 이력과 연결하여 설명한다. 사이클 값으로 업체 생산성 순위를 매기지 않는다.

### 4.2 준비 설정

## 5. 실습 D — 보이드 원인 비교

### 5.1 목적

TC-NCF의 스퀴즈·경화·기포 포획 경향과 MR-MUF의 유동 전선 미도달을 구분한다. 필러 막힘 경고와 미충전 면적률이 별개임을 확인한다.

### 5.2 준비 설정과 웹 입력 범위

공통 조건에서 TC 기본 결과를 확인한 뒤 **S5 가압 충전**을 실행한다. S5는 12단 MR-MUF의 **간격 7/15/20 μm × 입구 압력 0/1/0.1/3 MPa** 조건을 실행한다. 압력 0은 모세관 단독 비교다.

| 항목 | 웹에서 변경 가능 여부 | 이 실습의 처리 |
|---|---|---|
| 간격 / 입구 유효 압력 | 가능 | 폼 또는 S5. 간격 선택 범위 7~30 μm, 입구 0.1~3 MPa 및 비교용 0 |
| 하중 / TC 헤드 / 승온 | 가능 | 원인 분리를 위해 공통값 유지. 필요시 별도 관찰로 분리 기록 |

2. 파라미터 근거에서 `ncf.film`을 검색한다. 기본 초기 두께 **19 μm = 간격 15 μm + 여유 4 μm**를 확인한다.

## 6. 실습 E — 알람 대응

### 6.1 목적

잘못된 레시피의 사전 입력 차단, 모델의 접합 온도 알람, 펌웨어의 경고·래치, 두 히터 충돌 차단을 구분하고 원인 제거 후 수동 복구를 연습한다.

### 6.2 준비 설정

1.4절 공통 설정으로 시작한다. 한계 초과 입력은 아래 params의 경고 값 **52 N 또는 410 ℃**를 레시피에 한 항목씩 입력하여 시험한다. 허용 하중 **50 N**, 헤드 **400 ℃**를 초과하므로 실행이 차단되어야 한다. **실물에서는 이 값을 설정하지 않는다.** 고장 주입은 별도 ‘알람·인터락’ 버튼을 사용한다.

### 6.3 절차

1. 하중 입력만 52 N으로 바꾼다. 입력 한계 오류를 기록하고 실행이 시작되지 않는지 확인한다. 40 N으로 복원한다.
2. 헤드 입력만 410 ℃로 바꾸어 같은 시험을 하고 300 ℃로 복원한다. 폼 입력 차단과 고장 주입 래치가 다른 기능임을 확인한다.
3. ‘고장 원인 해제’ → ‘수동 래치 리셋’으로 시작 상태를 만든다. ‘과하중 경고 52 N’을 누르고 경고와 래치를 각각 기록한다. 원인을 해제한다.
4. ‘과하중 래치 55 N’을 누른다. 래치·두 히터 출력을 기록한다. 원인이 남은 상태로 수동 리셋하여 래치가 유지되는지 확인한다.
5. ‘고장 원인 해제’ 후에도 래치가 유지되는지 확인하고, ‘수동 래치 리셋’을 눌러 복구한다.
6. ‘과온 경고 410 ℃’를 확인한 뒤 원인을 해제한다. ‘과온 래치 420 ℃’, ‘하드웨어 고장’도 각각 4~5단계 순서로 시험한다. 한 고장마다 복구 후 다음 고장을 주입한다.
7. 원인 해제·수동 리셋 후 ‘헤드 통전 중 척 히터 요청’을 누른다. 차단 문구와 헤드/척 출력을 기록한다. 원인을 해제하여 요청을 정리한다.
8. S1의 모델 접합 온도 미달과 이번 래치 시험이 서로 다른 경로임을 설명한다. 일일 점검 기록은 7.3절 양식에도 남긴다.

### 6.5 확인 질문

1. 원문 최대 하중 50 N과 경고 52 N·래치 55 N을 왜 구분해야 하는가?
2. 고장 원인 해제만으로 래치가 풀리지 않는 이유는 무엇인가?
3. 두 히터 요청 차단은 고장 래치와 같은 동작인가?
4. 웹에서 고장 차단을 확인했다고 실물 센서·배선·안전 릴레이가 검증되었다고 할 수 있는가?

### 6.6 예상 결과와 해석

한계값은 [params](../../sim/params.json)의 `equipment_limits`, 동작은 [펌웨어 README](../../firmware/README.md)의 인터락·두 히터 계약에서 옮겼다. 웹 상태와 대응한 검증 항목은 [HMI 시험](../../sim/test/hmi.test.js)의 `HMI uses real wasm warning, latch persistence, manual reset and mutual heater exclusion`이다. 이 절은 임의 공정 계산값 대신 저장된 **설계 한계와 검증된 상태 전이**를 제시한다.

| 시험 | 예상 결과 |
|---|---|
| 레시피 52 N / 410 ℃ | 하중 50 N / 헤드 400 ℃ 한계 오류로 새 실행 차단. 이것만으로 고장 인스턴스 래치가 발생하는 것은 아님 |
| 경고 52 N / 410 ℃ | 정상 시작 상태에서 경고 1, 래치 0 |
| 래치 55 N / 420 ℃ / HW 고장 | 래치 1, 두 히터 모두 0 W. 원인 잔존 리셋은 재래치 |
| 원인 해제 → 수동 리셋 | 원인 해제만으로 래치 1 유지, 이어 수동 리셋하면 래치 0 |
| 헤드 통전 중 척 요청 | 헤드 >0 W, 척 0 W, 동시 통전 금지·차단 표시. 비래치 충돌 경고 |

400 ℃·50 N은 원문 KPI이고 410/420 ℃·52/55 N은 보호 계층 **설계값**이다. 보호 여유를 운전 허용 범위로 쓰지 않는다. 충돌 차단은 양쪽을 동시에 켜지 않도록 요청을 중재하며 기존 고장 래치와 다르다. 두 출력이 0인 전환 주기를 거친 뒤 다른 히터를 허용한다.

### 6.7 주의·모델 한계

웹 주입값은 시연 입력이며 고장 시험은 독립 wasm 인스턴스다. 고장 주입이 3D·적층 결과·독립 SIL을 모두 정지시키는 통합 실물 시험은 아니다. 히터 통전 판정도 실제 전류가 아닌 수락 지령 기준이다. 실물 MCU HAL·센서·안전 출력은 bring-up 전이며 웹 확인으로 제작 후 안전 시험을 대체하지 않는다. 공정 조건의 가정값, S3 휨 불일치, NCF 보이드 정량 모델 부재는 알람 복구로 해소되지 않는다.

## 7. 안전 — 실물 장비를 운전한다고 가정한 수칙

### 7.1 위험 요소와 보호 계층

이 장은 [PLAN 9.2절](../PLAN.md#92-안전-항목-추가), [중간 보고서 13.6~13.7절](../report/midterm/13_교육안전.md), [하드웨어 계산](../../calc/hardware/README.md), [펌웨어 계약](../../firmware/README.md)을 요약한다. 현재 학생 실습은 웹으로 수행한다. 실물 장비는 제작 후 시험과 지도자의 운전 승인을 거쳐야 한다.

| 위험·구역 | 실물 운전 가정 수칙 | 현재 근거와 제한 |

안전 계층은 레시피 입력 한계, 경고·고장 래치, 독립 비상정지·도어 인터락으로 구성한다. 고장 래치는 히터 차단·Z 정지·STO·브레이크 경로를 모사하며 원인 확인 후 수동 해제한다. 실제 비교기·배선·브레이크 동작은 웹의 숫자 표시와 별개로 시험한다.

### 7.2 시작·운전·종료

1. 시작 전 배기·냉각수 유량·누수·접지·커버·비상정지·도어 인터락을 확인한다. 툴 오염·로드셀 영점·시편 전면 지지와 지그 시험 완료 기록을 확인한다.
2. 정렬 온도를 고정하고 **설정 온도 도달 후 90 s 안정화**한 다음 기준 다이로 비전 채널 오프셋을 보정한다. 적층 척과 리플로우 척을 같은 척으로 쓰는 구성에도 적용한다. 90 s는 절차 설계값이며 실제 열평형 보증이 아니다.
3. 7.3절 일일 인터락 확인을 마친 뒤 시편·레시피를 확인한다. 실물 저하중 작업은 알맞은 레인지 장착 여부를 별도 확인한다.
4. 운전 중 커버를 유지하고 헤드와 척 히터를 순차 사용한다. 고장 시 원인 확인 없이 반복 리셋하거나 인터락을 우회하지 않는다.
5. 종료 시 두 히터 요청을 끄고 냉각 상태와 경고등을 확인한다. 냉각 FAIL/REVIEW를 고려해 대기 여유를 확보하고 **50 ℃ 이하** 확인 후 커버를 열어 시편·잔여 수지를 정리한다.
6. 안전한 종료 상태를 확인한 뒤 냉각수·N₂·전원을 정리한다. 웹 실습은 고장 원인 해제와 수동 리셋 상태를 기록하고 종료한다.

### 7.3 일일 인터락 동작 확인 절차 — 웹 연습 가능

실습 E의 버튼으로 아래 순서를 연습한다. **고장 주입 3종은 과하중 래치·과온 래치·하드웨어 고장**이다. 실제 장비에서 과하중·과온을 만들라는 지시가 아니며, 실물에서는 승인된 시험 수단으로 보호 경로를 확인한다.

1. wasm 초기화와 정상 상태를 확인한다. ‘고장 원인 해제’ → ‘수동 래치 리셋’으로 잔존 원인과 래치를 정리한다.
2. ‘과하중 래치 55 N’을 주입한다. 래치 1·헤드/척 0 W를 확인한다. 원인이 남은 채 리셋해도 해제되지 않는지 확인한다.
3. ‘고장 원인 해제’를 누른다. 래치 1이 유지되는지 확인한 뒤 ‘수동 래치 리셋’으로 0 복귀를 확인한다.
4. ‘과온 래치 420 ℃’와 ‘하드웨어 고장’에 대해 2~3단계를 각각 반복한다. 고장별 차단·원인 해제·수동 리셋을 모두 기록한다.
5. 정상 복구 후 ‘헤드 통전 중 척 히터 요청’을 누른다. 동시 요청 차단 표시, 헤드 >0 W·척 0 W를 확인한다. 이 충돌 경고는 비래치다.
6. ‘고장 원인 해제’로 척 요청과 고장 원인을 정리하고, 래치가 있으면 수동 리셋한다. 웹의 이 버튼은 척 요청을 0으로 만들며 헤드 활성은 유지한다. 따라서 복구 후 헤드 출력이 다시 허용될 수 있다. 실물 복구에서는 재시작을 원하지 않으면 두 히터 요청을 먼저 끈 뒤 리셋한다.
7. 확인 실패·wasm 초기화 실패는 문구를 기록하여 지도자에게 알린다. 실물 운전은 점검 실패 원인을 해소하고 재확인하기 전 시작하지 않는다.

웹 버튼은 헤드 통전 중 척 요청 방향을 제공한다. 반대 방향 차단·출력 0 전환 주기·동시 요청 시 헤드 우선 규칙은 펌웨어 시험으로 확인한 계약이며 웹 버튼으로 모두 조작할 수 있는 것은 아니다. 상태의 통전은 실제 전류가 아닌 **HAL 수락 지령 >0 W** 기준이다.

## 부록 B. 용어

| 용어 | 뜻 |
|---|---|
| TC-NCF | Thermo-Compression / Non-Conductive Film. 층별 열압착과 비전도성 필름을 사용하는 공정 |
| MR-MUF | Mass Reflow / Molded Underfill. 전체 리플로우 후 몰딩 언더필을 충전하는 공정 |
| 가접(tack) | 다음 층 취급을 위한 순간 가열·임시 고정. 리플로우와 구분 |
| 자기 접합 구간 | 해당 다이를 접합하는 자신의 본딩 구간. 후속 층 재가열과 구분 |
| 재가열 | 자체 접합 후 후속 본딩에 노출되는 이벤트. 액상선 도달 여부와 독립 |
| 액상선 교차 / 후속 재용융 | 액상선 상향 통과 총수(첫 용융 포함) / 첫 용융을 제외한 추가 통과 수 |
| TAL | 액상선 위 체류 시간. 어떤 기준 온도·공정 구간을 썼는지 함께 기록 |
| BLT·스탠드오프 | 접합층 두께·다이 사이 최종 간격. 초기 필름 두께와 구분 |
| 스퀴즈·겔화 | 하중으로 수지가 밀려 흐르는 과정·경화로 유동이 제한되는 상태 |
| 보이드 / 미충전 | 갇힌 기체 등의 빈 영역 / 충전 전선이 도달하지 못한 영역. 현재 MR 면적률은 미충전만 계산 |
| 입구 유효 압력 | 칩 사이 유로 입구에 실제로 작용한다고 가정한 압력. 금형 인가 압력과 다름 |
| NCC·서브픽셀·아핀 | 정규화 상호상관 검출·픽셀보다 작은 중심 추정·영상 좌표의 변환 보정 |

| 3σ·누적 정렬 | 표준편차 기반 통계 지표·층별 오차가 쌓인 표본 위치. 판정 용도를 구분 |
| 본더 점유 / 배치 후공정 | 본더가 스택에 쓰는 시간 / 리플로우·몰딩·경화 등의 배치 시간. 라인 UPH와 다름 |
| SIL·wasm·HAL | Software-in-the-Loop·웹에서 공통 제어기를 실행하는 형식·하드웨어 추상 계층 |
| 래치·수동 리셋 | 원인이 사라져도 고장 상태를 유지하는 기능·사람의 명시적 복구 조작 |
| STO | Safe Torque Off. 토크 차단 경로이며 웹에서는 모사 |
| FAIL/REVIEW | 계산의 설계 목표 미달 또는 검토 필요 상태. 실물 운전 승인으로 해석하지 않음 |
