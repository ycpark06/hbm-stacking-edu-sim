# 신규 하드웨어 계산 4종

저장소 루트에서 `/Library/Frameworks/Python.framework/Versions/3.12/bin/python3 calc/hardware/run_all.py`를 실행한다. 네 JSON을 덮어쓰고 판정표를 출력한다. 정상 실행 종료코드 0은 계산 실행 성공이며 설계 합격을 뜻하지 않는다. 현재 네 계산의 종합 판정은 모두 **FAIL/REVIEW**다. 결과를 맞추기 위한 입력 조정은 하지 않았다.

치수는 `cad/stacker/spec_stacker.py`(중간 spec 확장), 공정·Si 물성은 읽기 전용 `sim/params.json`, 추가 물성·가정은 `hw_params.json`에서 읽는다. 각 JSON의 inputs에 값·단위·구분·출처를 보존한다. `hw_params.json`의 대표 물성은 문헌 인증값이 아닌 대리 가정이며 고온 물성·보드 BOM·실측 확인이 필요하다.

## FAIL/REVIEW와 설계 제안

- **전원·열:** 중간 48 V 600 W에서 헤드400+척120+보조100=620 W로 20 W 초과한다. 헤드 출력을 금지하는 순차운전(220 W) 또는 동시사용 시 48 V 750 W 이상 전원 변경을 제안한다. 3 K/s는 120.687 W로 후보 히터120 W를 넘으므로 전체 1~3 K/s 범위를 만족한다고 주장할 수 없다. 탑재물·볼트 열손실을 포함해 히터 용량 여유를 재설계해야 한다. 자연냉각 초기0.405 K/s로 4 K/s 목표를 추종하지 못한다. 강제냉각 초기7.693 K/s는 고정 h=400 가정이며 유량 제어/실측이 필요하다. 250 ℃는 리플로우 공정 목표로, 헤드 최고400 ℃ 원문 KPI 충족 검증과 별개다. 600 W는 중간 전원 사양, 1~3/4 K/s는 공정 목표이며 원문 KPI가 아니다.
- **금형 체결:** 플런저 압력은 생성 가능하지만 3 MPa×36 mm²=108 N 개방력은 원문 최대 하중50 N을 넘는다. Z축 단독 형체결은 불가하다. 독립 M3 나사4개, 합계 예압216 N 이상을 제안하되 나사·유리·밀봉면 내압과 수지 포집기를 검증해야 한다. 대기 위치의 금형을 Z축 아래 교환 장착하는 상세는 미확정이다. H7/g6는 가이드 틈새이며 수지 씰이 아니다.
- **다이 지지:** 평균 압축압력이 낮다는 이유만으로 파손 없음 판정은 불가하다. 50 μm 무지지 다이의 단순 보 상한은24,000 MPa로 모델 적용 한계와 전면 지지 필요성을 보인다. 석영 전면 받침·접촉층 강성·평탄도·범프 분포를 설계/시험하고 모서리 결함 및 굽힘을 포함한 시험/FEA가 필요하다. 40 N은 공정 가정으로50 N KPI 이내지만 파손 안전성은 미입증이다. 척2 μm 평면도는 설계 목표이며 ±1 μm 정합 KPI와 동일한 항목이 아니다. AlN/MACOR 탄성계수는 Si 대리라 축 수축량도 예비값이다.
- **열정렬:** 상온 정렬좌표를250 ℃에 그대로 사용할 수 없다. 고온 현위치 비전 재정렬, 대칭/미끄럼 체결, 척 온도 실측 안정화를 제안한다. 중간 헤드90 s 대기 규칙을 척에 그대로 적용하지 않는다. ±1 μm 원문 정합 KPI에 대해 Si 상대 이동96.60 μm는 중간 열예산0.26 μm를 크게 초과한다. 이는 체계 오프셋이므로 기존 RSS에 제곱합하지 않는다. 고온 평면도2 μm도 현재 입증되지 않았다.

## 플런저 선택·끼워맞춤

3 MPa에서 마찰 없는 이론 최대 지름은 `sqrt(4×50/(π×3))=4.60659 mm`다. 후보 Ø4 mm는37.699 N, 마찰예약5 N 포함42.699 N으로50 N 이하다. 같은5 N 예약을 적용하면 최대 지름은4.37019 mm다. Ø4.5 mm는 이상47.713 N이지만 예약 포함52.713 N이므로 선택하지 않는다. Ø5/6 mm는 이상58.905/84.823 N으로 불가하다. Ø3 mm는 이상21.206 N이다.

Ø4 H7/g6: 보어4.000~4.012 mm, 축3.988~3.996 mm, 냉간 직경 틈새4~24 μm. 균일250 ℃·동일 SUS304 팽창 가정에서4.016~24.094 μm다. 온도차/실링/마찰 실측은 포함하지 않았다. 3 MPa 금형압력은 문헌값이며 스택 간격 입구 유효압력과 같은 값으로 간주하지 않는다. 52 N은 소프트웨어 경고 계층, 55 N은 래치로서 허용 공정 하중을 높이는 근거가 아니다.

## 검증 범위

집중정수 Bi 상한0.0192, 냉각 dt/2 시간차 약4.2e-12 s는 수치 검사 결과다. 시간격자 오차가 작아도 물리모델 정확성 보증은 아니다. 면내 균일성·부착물 열용량·열교·접합부/스테이지 강성은 미포함이며 실제 프로파일·다이 강도·내압·고온 정합 검증이 남아 있다. geometry/parts 입력은 공유 원본을 기록하지만 재료 공급자 성적서의 대체물이 아니다.
